Question 361 / 361

Your company has deployed an artificial intelligence model in a central project. This model contains sensitive intellectual property and must be kept strictly isolated from the internet. You must expose the model endpoint only to a defined list of projects in your organization. What should you do?

  • A. Within the model project, create an internal Application Load Balancer that points to the model endpoint. Expose this load balancer with Private Service Connect to a configured list of projects.
  • B. Activate Private Google Access in both the model project and in each project that needs to connect to the model. Create a firewall policy to allow connectivity to Private Google Access addresses.
  • C. Create a central project to host Shared VPC networks that are provided to all other projects. Centrally administer all firewall rules in this project to grant access to the model.
  • D. Within the model project, create an external Application Load Balancer that points to the model endpoint. Create a Cloud Armor policy to restrict IP addresses to Google Cloud.
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

Poprawna odpowiedź: A (Within the model project, create an internal Application Load Balancer that points to the model endpoint. Expose this load balancer with Private Service Connect to a configured list of projects.)

Dlaczego ta odpowiedź jest poprawna:
- Private Service Connect (PSC): To najbezpieczniejszy (prywatny) sposób wystawiania usług (np. za Load Balancerem) do innych projektów (service consumption) bez konieczności zestawiania sieci typu VPC Peering czy Shared VPC.
- "Expose ... to a defined list of projects": PSC pozwala na precyzyjne określenie, *które* projekty mogą połączyć się z usługą.
- "Isolated from the internet": Użycie Internal Application Load Balancer w połączeniu z PSC gwarantuje brak publicznego dostępu.

Analiza niepoprawnych odpowiedzi:
- B: Private Google Access pozwala na dostęp do usług *Google* (API), a nie do Twojego własnego endpointu usługi.
- C: Shared VPC to zmiana całej architektury sieciowej, a nie rozwiązanie problemu ekspozycji endpointu.
- D: External Load Balancer = publiczny dostęp. Nie spełnia wymogu "strictly isolated from the internet".

Wskazówki i triki (Tips & Tricks):
- "Expose ... to a defined list of projects" + "Isolated from internet" + "Private" = Private Service Connect (PSC).

Praktyczne informacje na egzamin:
- Zapamiętaj: PSC to standard dla bezpiecznego, prywatnego "service consumption" w GCP.
