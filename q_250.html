Question 250 / 361

You are managing data in your organization's Cloud Storage buckets and are required to retain objects. To reduce storage costs, you must automatically downgrade the storage class of objects older than 365 days to Coldline storage. What should you do?

  • A. Use Cloud Asset Inventory to generate a report of the configuration of all storage buckets. Examine the Lifecycle management policy settings and ensure that they are set correctly.
  • B. Set up a CloudRun Job with Cloud Scheduler to execute a script that searches for and removes files older than 365 days from your Cloud Storage.
  • C. Enable the Autoclass feature to manage all aspects of bucket storage classes.
  • D. Define a lifecycle policy JSON with an action on SetStorageClass to COLDLINE with an age condition of 365 and matchStorageClass STANDARD.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
D. Define a lifecycle policy JSON with an action on SetStorageClass to COLDLINE with an age condition of 365 and matchStorageClass STANDARD.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Odpowiedź D jest prawidłowa, ponieważ obiektowe zarządzanie cyklem życia (Object Lifecycle Management) w Cloud Storage jest natywną, zautomatyzowaną i bezkosztową funkcją służącą do zarządzania przechowywaniem danych i optymalizacji kosztów.

Zasada działania:
a. **Reguły cyklu życia (Lifecycle Rules):** Pozwalają na zdefiniowanie zestawu warunków (conditions) i akcji (actions).
b. **Konfiguracja:** Warunek wieku (`age: 365`) i typu początkowego (`matchStorageClass: ["STANDARD"]`) w połączeniu z akcją `SetStorageClass` ustawioną na `COLDLINE` sprawia, że Cloud Storage automatycznie zidentyfikuje obiekty starsze niż rok i przeniesie je do tańszej klasy przechowywania Coldline. Proces ten odbywa się w tle, bez konieczności pisania kodu i ponoszenia kosztów za operacje compute.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
A. Use Cloud Asset Inventory to generate a report... Examine the Lifecycle management policy...
   * Dlaczego nieprawidłowa: Cloud Asset Inventory generuje raporty konfiguracyjne. Pomoże sprawdzić, czy polityka istnieje, ale samo wygenerowanie raportu nie konfiguruje i nie wykonuje operacji migracji danych do klasy Coldline.
B. Set up a CloudRun Job with Cloud Scheduler to execute a script...
   * Dlaczego nieprawidłowa: Rozwiązanie to wymaga napisania własnego kodu, utrzymywania infrastruktury (Cloud Run) i generuje koszty (Scheduler, Cloud Run, operacje API na Cloud Storage). Co więcej, skrypty wyszukujące i przenoszące dane w skali petabajtów są nieefektywne i powolne w porównaniu do natywnego mechanizmu Lifecycle Management w chmurze.
C. Enable the Autoclass feature to manage all aspects of bucket storage classes.
   * Dlaczego nieprawidłowa: Funkcja Autoclass automatycznie przenosi dane między klasami (Standard, Nearline, Coldline, Archive) w zależności od częstotliwości rzeczywistego dostępu (access patterns) do obiektów. Nie pozwala na sztywne wymuszenie przejścia do klasy Coldline dokładnie po 365 dniach, jeśli dane są nadal sporadycznie odpytywane, co może nie przynieść pożądanej redukcji kosztów zgodnie ze zdefiniowanym wymaganiem wieku.

4. Wskazówki, hinty, tips and tricks:
* Automatyczne przenoszenie danych między klasami przechowywania (storage classes) w Cloud Storage lub ich usuwanie po określonym czasie -> Zawsze używaj **Object Lifecycle Management**.
* Warunki w polityce cyklu życia obejmują: wiek (age), datę utworzenia, liczbę nowszych wersji (dla wersjonowania) itp.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
* Downgrade storage class of objects older than X days -> Lifecycle policy JSON / SetStorageClass action.
