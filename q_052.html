Question 52 / 361

Which tool can help identify and classify sensitive information (like credit card numbers) in unstructured text?

  • A. Cloud KMS
  • B. Cloud DLP API
  • C. BigQuery
  • D. Data Catalog
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Poprawna odpowiedź: B (Cloud DLP API)

Analiza poprawności:
Usługa Cloud DLP (obecnie Sensitive Data Protection) posiada zaawansowane silniki analizy tekstu oparte na przetwarzaniu języka naturalnego (NLP). Dzięki nim potrafi w strumieniu nieustrukturyzowanego tekstu (np. czat, komentarz, logi) automatycznie wykryć wzorce typowe dla danych wrażliwych (PII - Personally Identifiable Information), takich jak numery kart płatniczych (np. wzorzec `CREDIT_CARD_NUMBER`), numery PESEL, adresy email czy numery telefonów. Jest to dedykowane narzędzie do "identyfikacji i klasyfikacji" takich informacji.

Dlaczego pozostałe są błędne:
A (Cloud KMS): Służy wyłącznie do bezpiecznego przechowywania i zarządzania kluczami szyfrującymi. Nie posiada żadnej funkcjonalności skanowania czy analizy treści danych.
C (BigQuery): To baza danych klasy Data Warehouse. Choć można w niej przechowywać dane, sama w sobie nie potrafi przeszukiwać tekstu w poszukiwaniu "wrażliwości" (PII) – do tego celu zazwyczaj używa się DLP API, które z BigQuery współpracuje.
D (Data Catalog): To usługa do inwentaryzacji metadanych (opisywania, tagowania, zarządzania słownikiem danych). Pozwala na tagowanie danych jako "wrażliwe", ale nie służy do aktywnego *wykrywania* tych danych w treści plików tekstowych.

Wskazówki egzaminacyjne:
- "Identify and classify" + "Sensitive information" / "PII": Szukaj "Cloud DLP API".
- "Unstructured text": To zawsze domena narzędzi NLP/DLP.
- Eliminacja: KMS (szyfrowanie), Data Catalog (metadane) – nigdy nie wybieraj ich jako narzędzi do "wykrywania" treści.

Dokumentacja:
https://cloud.google.com/dlp/docs/inspecting-text

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: B

Analiza spornych kwestii (AI): DLP używa kombinacji wyrażeń regularnych, sum kontrolnych (np. algorytm Luhna dla kart kredytowych) i modeli ML, aby minimalizować liczbę pomyłek (false positives) przy wykrywaniu wrażliwych danych w dużych zbiorach.
