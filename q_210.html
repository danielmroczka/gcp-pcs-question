Question 210 / 361

Your company uses Google Cloud and has publicly exposed network assets. You want to discover the assets and perform a security audit on these assets by using a software tool in the least amount of time.
What should you do?

  • A. Run a platform security scanner on all instances in the organization.
  • B. Identify all external assets by using Cloud Asset Inventory, and then run a network security scanner against them.
  • C. Contact a Google approved security vendor to perform the audit.
  • D. Notify Google about the pending audit, and wait for confirmation before performing the scan.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Poprawna odpowiedź: B (Identify all external assets by using Cloud Asset Inventory, and then run a network security scanner against them)

Dlaczego ta odpowiedź jest poprawna:
- Cloud Asset Inventory (CAI): Jest to usługa Google Cloud, która utrzymuje pełną, historyczną bazę danych wszystkich zasobów w Twojej organizacji. Pozwala na błyskawiczne (w czasie niemal rzeczywistym) wyszukiwanie zasobów na podstawie ich metadanych (np. "znajdź wszystkie instancje z przypisanym zewnętrznym adresem IP"). Jest to najszybsza metoda odkrywania (Discovery) rozproszonych zasobów.
- Network Security Scanner: Po zidentyfikowaniu celów (zewnętrznych IP), użycie automatycznego skanera bezpieczeństwa (np. Google Cloud Web Security Scanner lub narzędzi zewnętrznych typu Nessus/Qualys) pozwala na szybkie przeprowadzenie audytu podatności bez konieczności ręcznego sprawdzania każdej maszyny.
- Minimalizacja czasu: Połączenie CAI (automatyczne odkrywanie) i skanera (automatyczny audyt) jest najbardziej efektywnym czasowo podejściem w dużej skali.

Analiza niepoprawnych odpowiedzi:
- A. Platform security scanner on all instances: Skanowanie WSZYSTKICH instancji (w tym tych wewnętrznych) może być bardzo czasochłonne i niepotrzebne, jeśli celem jest audyt aktywów WYSTAWIONYCH na zewnątrz. Ponadto "platform security scanner" to termin mało precyzyjny w porównaniu do dedykowanego CAI.
- C. Contact a Google approved vendor: Zaangażowanie zewnętrznej firmy audytorskiej wiąże się z procesami biurokratycznymi, negocjacjami i wysokimi kosztami. Z pewnością nie jest to metoda pozwalająca na wykonanie zadania "w najkrótszym możliwym czasie" (least amount of time) w porównaniu do narzędzi zautomatyzowanych.
- D. Notify Google and wait: Zgodnie z zasadami Google Cloud, klienci mogą przeprowadzać własne skany bezpieczeństwa (vulnerability scans) na swoich zasobach bez konieczności uprzedniego powiadamiania Google. Czekanie na potwierdzenie byłoby stratą czasu.

Wskazówki i triki (Tips & Tricks):
- "Discover assets" / "Visibility" + "Least time" = Cloud Asset Inventory.
- "Audit vulnerabilities" + "Network level" = Network Security Scanner.
- Pamiętaj: Cloud Asset Inventory pozwala na zapytania typu SQL (Search All Resources), co daje wynik w sekundach dla całej organizacji.

Praktyczne informacje na egzamin:
- Zrozum różnicę: **Discovery** (Wiem, co mam) vs **Auditing** (Wiem, czy to co mam jest bezpieczne).
- Cloud Asset Inventory wspiera nie tylko aktualny stan, ale pozwala też sprawdzić konfigurację z przeszłości (Time travel).

Analiza i Podsumowanie (AI)

Kluczowe zagadnienia

Sugerowana odpowiedź: B

Analiza strategiczna: To pytanie testuje Twoją sprawność operacyjną w chmurze. W dynamicznym środowisku aktywa pojawiają się i znikają w minutach. Tradycyjne metody (arkusze Excel, ręczne inwentaryzacje) zawodzą. Cloud Asset Inventory to "szkielet" widoczności w GCP, a automatyczne skanery to "mięśnie" audytu. Ta synergia jest podstawą nowoczesnego Security Operations.

Dodatkowe wskazówki

  • Warto wiedzieć, że Cloud Asset Inventory może eksportować dane do BigQuery, co ułatwia budowanie niestandardowych raportów zgodności.
  • Pamiętaj o uprawnieniach: do przeszukiwania zasobów potrzebujesz roli `cloudasset.viewer` na poziomie organizacji.
