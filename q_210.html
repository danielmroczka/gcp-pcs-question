Question 210 / 361

Your company uses Google Cloud and has publicly exposed network assets. You want to discover the assets and perform a security audit on these assets by using a software tool in the least amount of time.

  • A. Run a platform security scanner on all instances in the organization.
  • B. Identify all external assets by using Cloud Asset Inventory, and then run a network security scanner against them.
  • C. Contact a Google approved security vendor to perform the audit.
  • D. Notify Google about the pending audit, and wait for confirmation before performing the scan.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Potwierdzona odpowiedź: B (Identify all external assets by using Cloud Asset Inventory, and then run a network security scanner against them).

Wyjaśnienie:
- Cloud Asset Inventory (CAI): Jest to usługa Google Cloud, która utrzymuje pełną bazę danych wszystkich zasobów w Twojej organizacji. Pozwala na błyskawiczne (w czasie niemal rzeczywistym) wyszukiwanie zasobów na podstawie ich metadanych (np. "znajdź wszystkie instancje z przypisanym zewnętrznym adresem IP"). Jest to najszybsza metoda odkrywania (Discovery) rozproszonych zasobów.
- Network Security Scanner: Po zidentyfikowaniu celów (zewnętrznych IP), użycie automatycznego skanera bezpieczeństwa (np. Web Security Scanner lub narzędzi zewnętrznych) pozwala na szybkie przeprowadzenie audytu podatności bez konieczności ręcznego sprawdzania każdej maszyny.
- Minimalizacja czasu: Połączenie CAI (automatyczne odkrywanie) i skanera (automatyczny audyt) jest najbardziej efektywnym czasowo podejściem w skali Enterprise.

Dlaczego pozostałe odpowiedzi są niepoprawne:
- A. Platform security scanner on all instances: Skanowanie WSZYSTKICH instancji (w tym wewnętrznych, baz danych itp.) może być bardzo czasochłonne i niepotrzebne, jeśli celem jest audyt aktywów WYSTAWIONYCH na zewnątrz. CAI precyzyjniej wskazuje cele.
- C. Contact a Google approved security vendor: Zaangażowanie zewnętrznej firmy wiąże się z procesami biurokratycznymi i wysokimi kosztami. Nie jest to metoda pozwalająca na wykonanie zadania "w najkrótszym możliwym czasie" w porównaniu do narzędzi natywnych.
- D. Notify Google and wait: Zgodnie z zasadami Google Cloud, klienci mogą przeprowadzać własne skany bezpieczeństwa (vulnerability scans) na swoich zasobach bez konieczności uprzedniego powiadamiania Google. Czekanie na potwierdzenie byłoby niepotrzebną stratą czasu.

Wskazówki egzaminacyjne (Tips & Tricks):
- "Discover assets" / "Visibility" + "Least time" = Cloud Asset Inventory.
- "Audit vulnerabilities" + "Network level" = Network Security Scanner.
- Pamiętaj: Cloud Asset Inventory pozwala na zapytania typu SQL (Search All Resources), co daje wynik w sekundach dla całej organizacji liczącej tysiące projektów.

Kluczowe zagadnienia do powtórzenia:
- Cloud Asset Inventory i eksport do BigQuery.
- Google Cloud Web Security Scanner.
- Zasady testów penetracyjnych i skanowania w GCP.
