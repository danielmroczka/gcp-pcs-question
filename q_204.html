Question 204 / 361

You are using Security Command Center (SCC) to protect your workloads and receive alerts for suspected security breaches at your company. You need to detect cryptocurrency mining software. Which SCC service should you use?

  • A. Virtual Machine Threat Detection
  • B. Container Threat Detection
  • C. Rapid Vulnerability Detection
  • D. Web Security Scanner
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

Potwierdzona odpowiedź: A (Virtual Machine Threat Detection).

Wyjaśnienie:
- VM Threat Detection (VMTD): Jest to usługa wchodząca w skład Security Command Center (SCC) Premium. Jej głównym zadaniem jest skanowanie pamięci RAM instancji Compute Engine w poszukiwaniu śladów złośliwego oprogramowania.
- Detekcja bezagentowa (Agentless): VMTD działa na poziomie hiperwizora Google, co oznacza, że nie wymaga instalowania żadnego oprogramowania (agenta) wewnątrz systemu operacyjnego VM. Dzięki temu jest niewidoczna dla atakującego i nie zużywa zasobów procesora maszyny.
- Crypto-mining: Jednym z głównych zastosowań VMTD jest wykrywanie oprogramowania do kopania kryptowalut (cryptomining), które często pojawia się na maszynach po ich nieautoryzowanym przejęciu. VMTD rozpoznaje charakterystyczne wzorce kodu i zachowania koparek bezpośrednio w pamięci maszyn Compute Engine.

Dlaczego pozostałe odpowiedzi są niepoprawne:
- B. Container Threat Detection: Służy do wykrywania zagrożeń (w tym koparek) wewnątrz kontenerów działających na GKE. Choć technicznie podobna, pytanie dotyczy ogólnie "workloads", a VMTD jest podstawową odpowiedzią dla klasycznych instancji VM w ekosystemie SCC.
- C. Rapid Vulnerability Detection: Służy do szybkiego skanowania publicznie dostępnych zasobów pod kątem znanych luk (np. słabe hasła, błędy w oprogramowaniu serwerowym). Nie skanuje pamięci pod kątem aktywnego malware.
- D. Web Security Scanner: Służy do szukania luk w aplikacjach webowych (np. SQL Injection, XSS). Nie służy do wykrywania koparek kryptowalut na poziomie systemu operacyjnego czy procesów systemowych.

Wskazówki egzaminacyjne (Tips & Tricks):
- "Detect cryptocurrency mining" + "Compute Engine" = VM Threat Detection.
- "Agentless memory scanning" = VM Threat Detection.
- Detekcja koparek jest priorytetem dla Google, ponieważ nieautoryzowany mining generuje ogromne koszty finansowe dla klientów i zużywa zasoby chmury.

Kluczowe zagadnienia do powtórzenia:
- Security Command Center Premium Services (VMTD, ETD, CTD).
- Agentless Security (bezpieczeństwo bezagentowe).
- Wykrywanie zagrożeń w czasie rzeczywistym (Runtime Threat Detection).
