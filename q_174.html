Question 174 / 361

You manage your organization's Security Operations Center (SOC). You currently monitor and detect network traffic anomalies in your VPCs based on network logs. However, you want to explore your environment using network payloads and headers. Which Google Cloud product should you use?

  • A. Cloud IDS
  • B. VPC Service Controls logs
  • C. VPC Flow Logs
  • D. Google Cloud Armor
  • E. Packet Mirroring
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
A. Cloud IDS

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Menedżer SOC chce mieć możliwość monitorowania, wykrywania anomalii oraz badania zagrożeń w sieci VPC na podstawie nagłówków i zawartości pakietów (payload):
- Cloud IDS (Intrusion Detection System) to w pełni zarządzana przez Google Cloud usługa bezpieczeństwa sieciowego. Służy do wykrywania włamań i złośliwego oprogramowania wewnątrz sieci VPC.
- Cloud IDS automatycznie przechwytuje ruch sieciowy i przesyła go do zaawansowanego silnika analizy zagrożeń (wykorzystującego technologie Palo Alto Networks), który bada nagłówki i całą zawartość (payload) pakietów sieciowych w poszukiwaniu sygnatur ataków. Jako gotowy **produkt** (usługa zarządzana PaaS), Cloud IDS dostarcza pełny interfejs analityczny i alerty o zagrożeniach bez konieczności wdrażania własnego oprogramowania IDS na maszynach wirtualnych.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- E. Packet Mirroring: Jest to podstawowa funkcja sieciowa (telemetria), która służy do kopiowania ruchu i przesyłania go do zewnętrznego systemu. Sama z siebie nie analizuje zagrożeń ani payloadu – wymaga od klienta samodzielnego zainstalowania, licencjonowania i konfigurowania oprogramowania IDS/IPS (np. Suricata) na maszynach wirtualnych, co czyni ją technologią bazową, a nie gotowym, zarządzanym produktem wykrywającym zagrożenia.
- B. Logi VPC Service Controls: Rejestrują wyłącznie błędy i blokady dostępu na poziomie API usług Google (np. BigQuery, GCS), nie monitorują ogólnego ruchu IP pomiędzy instancjami VM wewnątrz sieci VPC.
- C. VPC Flow Logs: Rejestrują tylko metadane ruchu (nagłówki połączeń), nie dając wglądu w zawartość (payload) pakietu.
- D. Google Cloud Armor: Chroni aplikacje na brzegu sieci (WAF) przed atakami DDoS, nie jest narzędziem typu IDS do ciągłego badania wewnętrznego ruchu sieciowego w VPC.

4. Wskazówki, hinty, tips and tricks:
- Cloud IDS to gotowa, zarządzana usługa bezpieczeństwa sieciowego (Intrusion Detection System) w GCP, która wewnętrznie korzysta z Packet Mirroring, ale oferuje pełną analitykę zagrożeń w payloadzie out-of-the-box.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Zarządzany produkt do wykrywania włamań i analizy payloadu/nagłówków w VPC -> Cloud IDS.

6. Dodatkowe źródła i dokumentacja:
- Cloud IDS overview: https://cloud.google.com/intrusion-detection-system/docs/overview
