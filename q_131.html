Question 131 / 361

You perform a security assessment on a customer architecture and discover that multiple VMs have public IP addresses. After providing a recommendation to remove the public IP addresses, you are told those VMs need to communicate to external sites as part of the customer's typical operations. What should you recommend to reduce the need for public IP addresses in your customer's VMs?

  • A. Google Cloud Armor
  • B. Cloud NAT
  • C. Cloud Router
  • D. Cloud VPN
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Potwierdzona odpowiedź: B (Cloud NAT).

Wyjaśnienie:
Cloud NAT (Network Address Translation) to usługa zarządzana, która pozwala instancjom maszyn wirtualnych (VM) bez publicznych adresów IP na bezpieczne nawiązywanie połączeń wychodzących do internetu. Dzięki Cloud NAT, maszyny posiadają jedynie prywatne adresy IP, co znacznie zmniejsza powierzchnię ataku (są niewidoczne i niedostępne bezpośrednio z zewnątrz), a jednocześnie zachowują możliwość pobierania aktualizacji czy komunikacji z zewnętrznymi API. Cloud NAT obsługuje zarówno Compute Engine, jak i węzły GKE.

Dlaczego pozostałe są błędne:
- A. Google Cloud Armor: Jest to usługa WAF i ochrony przed DDoS dla ruchu przychodzącego (ingress) przez load balancery. Nie służy do zapewniania łączności wychodzącej dla maszyn z prywatnymi IP.
- C. Cloud Router: Cloud Router odpowiada za dynamiczną wymianę tras (BGP) pomiędzy siecią VPC a siecią on-premises (przez VPN lub Interconnect). Sam w sobie nie zapewnia translacji adresów NAT dla ruchu internetowego. Cloud NAT wymaga Cloud Routera do działania, ale to NAT realizuje funkcję wyjścia do internetu.
- D. Cloud VPN: Służy do bezpiecznego łączenia sieci VPC z innymi sieciami (np. biurem lub inną chmurą) przez tunel IPsec. Nie jest to rozwiązanie przeznaczone do ogólnej komunikacji VM z publicznymi stronami internetowymi w celu redukcji publicznych IP.

Wskazówki egzaminacyjne (Tips & Tricks):
- Słowo klucz "reduce/remove public IP" + "communicate to external sites" = zawsze Cloud NAT.
- Cloud NAT jest usługą typu "egress-only" – pozwala na wyjście do internetu, ale nie pozwala internetowi na zainicjowanie połączenia z maszyną.
- Pamiętaj, że Cloud NAT jest powiązany z Cloud Routerem, ale to dwie różne funkcje.

Kluczowe zagadnienia do powtórzenia:
- Cloud NAT i jego architektura.
- Bezpieczeństwo sieci VPC (brak publicznych adresów IP).
- Private Google Access (komunikacja z API Google bez publicznego IP).
