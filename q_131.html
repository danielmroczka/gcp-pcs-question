Question 131 / 361

You perform a security assessment on a customer architecture and discover that multiple VMs have public IP addresses. After providing a recommendation to remove the public IP addresses, you are told those VMs need to communicate to external sites as part of the customer's typical operations. What should you recommend to reduce the need for public IP addresses in your customer's VMs?

  • A. Google Cloud Armor
  • B. Cloud NAT
  • C. Cloud Router
  • D. Cloud VPN
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
B. Cloud NAT

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Audyt wykazał, że maszyny wirtualne posiadają publiczne adresy IP. Maszyny te muszą jednak komunikować się z zewnętrznymi witrynami (ruch wychodzący, np. aktualizacje oprogramowania, zapytania API):
- Cloud NAT (Network Address Translation) to w pełni zarządzana i bezpieczna usługa, która pozwala instancjom maszyn wirtualnych bez zewnętrznych (publicznych) adresów IP na inicjowanie połączeń z internetem. Ruch wychodzący z maszyn o prywatnych adresach IP jest tłumaczony na bramie Cloud NAT na publiczny adres IP. Pozwala to na bezpieczne usunięcie publicznych adresów IP z maszyn wirtualnych, drastycznie zmniejszając ich powierzchnię ataku (ruch z internetu nie może bezpośrednio dotrzeć do maszyny).

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- A. Google Cloud Armor: Służy do ochrony przed atakami DDoS i filtrowania ruchu przychodzącego do Load Balancerów. Nie zapewnia translatora adresów IP dla wychodzącego ruchu maszyn wirtualnych.
- C. Cloud Router: Sam w sobie odpowiada za wymianę dynamicznych tras routingu przy użyciu protokołu BGP (np. dla Interconnect czy VPN). Cloud NAT wymaga Cloud Routera do działania, ale to sam Cloud NAT realizuje translację adresów i eliminuje potrzebę posiadania publicznych IP.
- D. Cloud VPN: Tworzy bezpieczny, zaszyfrowany tunel do połączenia z siecią lokalną (on-premises) lub inną siecią VPC. Nie służy do ogólnego wyjścia prywatnych maszyn wirtualnych na publiczne strony internetowe.

4. Wskazówki, hinty, tips and tricks:
- Usuwanie publicznych adresów IP z maszyn + potrzeba dostępu maszyn do internetu -> Zawsze wybieraj **Cloud NAT**.
- Pamiętaj, że bramę Cloud NAT konfiguruje się na poziomie Cloud Routera dla danej sieci VPC i jej podsieci.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Usunięcie zewnętrznych IP z VM + dostęp maszyn do internetu (outbound traffic) -> Cloud NAT.

6. Dodatkowe źródła i dokumentacja:
- Cloud NAT overview: https://cloud.google.com/nat/docs/overview

Analiza i Podsumowanie Dyskusji (AI)

Reguła Egzaminacyjna (Exam Rule)

Dla każdej architektury, która wymaga "izolacji publicznej" przy jednoczesnym zachowaniu łączności wychodzącej, Cloud NAT jest jedyną słuszną odpowiedzią w GCP.

Haczyki Egzaminacyjne (Exam Traps)

  • Cloud Router vs Cloud NAT: Egzamin często zestawia te usługi. Zapamiętaj: Router to "mózg" (zarządzanie trasami BGP), NAT to "narzędzie" (translacja adresów). Sam Router nie zapewni wyjścia do internetu.
  • Myśl o NAT jako o firewallu: Pamiętaj, że Cloud NAT nie otwiera połączeń przychodzących. Jeśli pytanie wspomina o potrzebie przyjmowania ruchu (np. web server), NAT nie wystarczy – potrzebny będzie Load Balancer.

Głębokie wyjaśnienie techniczne (GCP Professional Cloud Security Engineer)

Cloud NAT działa jako usługa typu Software-Defined Networking (SDN) w warstwie zarządzanej GCP. Wykorzystuje IP masquerading, mapując prywatne adresy IP instancji (z zakresu RFC 1918) na jeden lub więcej publicznych adresów IP zarezerwowanych dla bramy NAT. Z punktu widzenia bezpieczeństwa, pozwala to na utrzymanie "Zero Trust" wewnątrz sieci VPC: maszyny nie są osiągalne z Internetu, co eliminuje ryzyko skanowania portów czy ataków typu brute-force bezpośrednio na instancje.
