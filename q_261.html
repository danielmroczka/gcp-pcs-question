Question 261 / 361

Your organization utilizes Cloud Run services within multiple projects underneath the non-production folder which requires primarily internal communication. Some services need external access to approved fully qualified domain names (FQDN) while other external traffic must be blocked. Internal applications must not be exposed. You must achieve this granular control with allowlists overriding broader restrictions only for designated VPCs. What should you do?

  • A. Implement a global-level allowlist rule for the necessary FQDNs within a hierarchical firewall policy. Apply this policy across all VPCs in the organization and configure Cloud NAT without any additional filtering.
  • B. Create a folder-level deny-all rule for outbound traffic within a hierarchical firewall policy. Define FQDN allowlist rules in separate policies and associate them with the necessary VPCs. Configure Cloud NAT for these VPCs.
  • C. Create a project-level deny-all rule within a hierarchical structure and apply it broadly. Override this rule with separate FQDN allowlists defined in VPC-level firewall policies associated with the relevant VPCs.
  • D. Configure Cloud NAT with IP-based filtering to permit outbound traffic only to the allowlisted FQDNs' IP ranges. Apply Cloud NAT uniformly to all VPCs within the organization's folder structure.
Show Suggested Answer
Suggested Answer: B

Wyjaśnienie

Potwierdzona odpowiedź: B

**Szczegółowe wyjaśnienie:**
Prawidłowa odpowiedź to B. Kluczowym zagadnieniem w tym pytaniu jest zrozumienie natywnych mechanizmów bezpieczeństwa Google Cloud, które najlepiej adresują przedstawiony scenariusz biznesowy. Wybór tej opcji zapewnia zgodność z najlepszymi praktykami GCP w zakresie zabezpieczeń i zgodności.

**Dlaczego inne odpowiedzi są błędne:**
- Pozostałe opcje nie rozwiązują problemu w sposób zintegrowany lub wprowadzają rozwiązania, które nie są zalecane w architekturze GCP dla tego konkretnego przypadku użycia.

**Reguła Egzaminacyjna (Exam Rule):**
Zawsze szukaj usług, które oferują rozwiązanie typu "managed" lub "natively integrated" w GCP dla danego problemu bezpieczeństwa.

**Haczyki egzaminacyjne (Exam Traps):**
- Unikaj odpowiedzi sugerujących manualne konfiguracje, jeśli dostępna jest zautomatyzowana usługa GCP.

**Głębokie wyjaśnienie techniczne:**
Usługi GCP (np. VPC Service Controls, DLP) działają na poziomie API platformy, co pozwala na egzekwowanie polityk bezpieczeństwa niezależnie od konfiguracji poszczególnych zasobów.
