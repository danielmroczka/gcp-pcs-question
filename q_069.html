Question 69 / 361

An organization uses a well-established directory service as the `source of truth`. They want to use GCP. Which solution meets the requirements?

  • A. Google Cloud Directory Sync (GCDS)
  • B. Cloud Identity
  • C. SAML
  • D. Pub/Sub
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

Potwierdzona odpowiedź: A (Google Cloud Directory Sync (GCDS))

Wyjaśnienie: 
Aby zachować lokalną usługę katalogową jako 'źródło prawdy' (source of truth), należy użyć narzędzia synchronizującego dane w jedną stronę (one-way sync) do Google Cloud. GCDS pobiera informacje z LDAP i aktualizuje Cloud Identity, zapewniając spójność danych bez zmiany ich pierwotnego źródła.

Dlaczego pozostałe są błędne:
B. Cloud Identity to usługa (platforma), w której przechowywane są konta, a nie narzędzie do synchronizacji.
C. SAML służy do Single Sign-On (federacja uwierzytelniania), a nie do synchronizacji/tworzenia kont w chmurze (choć może być używany razem z JIT provisioning, GCDS jest bardziej kompletnym rozwiązaniem dla zarządzania cyklem życia).
D. Pub/Sub to usługa przesyłania wiadomości, nie służy do zarządzania tożsamościami.

Wskazówki egzaminacyjne (Tips & Tricks):
'Source of truth' on-premises + GCP = GCDS.

Kluczowe zagadnienia do powtórzenia:
- Identity Source of Truth
- GCDS vs SAML
- Cloud Identity architecture

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: A

Głęboka analiza: To klasyczne pytanie testujące zrozumienie różnicy między narzędziami do synchronizacji baz tożsamości (GCDS) a mechanizmami ich federacji (SAML). Organizacje z on-premises zawsze potrzebują GCDS jako fundamentu zarządzania użytkownikami.
