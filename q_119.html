Question 119 / 361

You are a member of your company's security team. You have been asked to reduce your Linux bastion host external attack surface by removing all public IP addresses. Site Reliability Engineers (SREs) require access to the bastion host from public locations so they can access the internal VPC while off-site. How should you enable this access?

  • A. Implement Cloud VPN for the region where the bastion host lives.
  • B. Implement OS Login with 2-step verification for the bastion host.
  • C. Implement Identity-Aware Proxy TCP forwarding for the bastion host.
  • D. Implement Google Cloud Armor in front of the bastion host.
Show Suggested Answer Hide Answer
Suggested Answer: C

Wyjaśnienie

Potwierdzona odpowiedź: C (Implement Identity-Aware Proxy TCP forwarding for the bastion host.)

Wyjaśnienie:
- IAP TCP Forwarding: Jest to usługa Google Cloud, która umożliwia bezpieczny dostęp SSH i RDP do maszyn wirtualnych znajdujących się w sieciach prywatnych (bez publicznego adresu IP).
- Redukcja powierzchni ataku: Dzięki temu rozwiązaniu bastion host nie potrzebuje publicznego adresu IP, co całkowicie eliminuje możliwość bezpośredniego ataku z internetu. Cały ruch jest tunelowany przez bezpieczny endpoint Google.
- Dostęp zdalny: Inżynierowie SRE mogą łączyć się z bastionem z dowolnej lokalizacji przez internet, autentykując się w Google Cloud (wymagana rola `roles/iap.tunnelResourceAccessor`).

Dlaczego pozostałe są błędne:
- A: Cloud VPN wymaga ustanowienia stałego tunelu między dwiema sieciami (lub klientem VPN). Jest to znacznie bardziej złożone w konfiguracji dla rozproszonych inżynierów łączących się z "publicznych lokalizacji" niż proste użycie IAP.
- B: OS Login z weryfikacją dwuetapową (2SV) zwiększa bezpieczeństwo samego procesu logowania do systemu operacyjnego, ale nie rozwiązuje problemu braku trasy do maszyny, która nie posiada publicznego adresu IP.
- D: Google Cloud Armor chroni wystawione na zewnątrz aplikacje webowe za Load Balancerem. Nie służy do zapewniania dostępu administracyjnego SSH do pojedynczych serwerów bastion.

Wskazówki egzaminacyjne (Tips & Tricks):
- "Remove public IP" + "Access via internet" = IAP TCP Forwarding.
- IAP to nowoczesna alternatywa dla tradycyjnych VPN-ów w zadaniach administracyjnych.

Kluczowe zagadnienia do powtórzenia:
- Jak działa tunelowanie IAP dla protokołów innych niż HTTP (TCP Forwarding).
- Wymagane uprawnienia IAM dla dostępu przez IAP.
- Reguły firewalla wymagane dla IAP (zezwolenie na zakres IP `35.235.240.0/20`).
