Question 236 / 361

You are deploying regulated workloads on Google Cloud. The regulation has data residency and data access requirements. It also requires that support is provided from the same geographical location as where the data resides. What should you do?

  • A. Enable Access Transparency Logging.
  • B. Deploy Assured Workloads.
  • C. Deploy resources only to regions permitted by data residency requirements.
  • D. Use Data Access logging and Access Transparency logging to confirm that no users are accessing data from another region.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Potwierdzona odpowiedź: B (Deploy Assured Workloads.)

Wyjaśnienie:
- Assured Workloads: Jest to usługa zaprojektowana specjalnie dla "regulated industry" (np. sektor publiczny, finanse, opieka zdrowotna). Pozwala ona na automatyczne wymuszanie lokalizacji danych (data residency) oraz, co kluczowe w tym pytaniu, zapewnia, że personel wsparcia technicznego Google spełnia określone wymogi geograficzne ("support is provided from the same geographical location").

Dlaczego pozostałe odpowiedzi są niepoprawne:
- A, D: Logging/Auditing pozwala na detekcję, ale nie gwarantuje spełnienia wymogów (np. nie wymusza lokalizacji wsparcia).
- C: Sama selekcja regionów jest dobrym krokiem, ale nie spełnia wymogu dotyczącego "wsparcia z tej samej lokalizacji" (support location).

Wskazówki i triki (Tips & Tricks):
- "Regulated industry" + "Data residency" + "Support location requirement" = Assured Workloads.

Praktyczne informacje na egzamin:
- Zapamiętaj: Assured Workloads to kompleksowe rozwiązanie do spełniania wymogów regulacyjnych.

Dokumentacja i linki:
- Assured Workloads overview

Wskazówki egzaminacyjne (Tips & Tricks)

Reguła Egzaminacyjna (Exam Rule): 
Jeśli scenariusz dotyczy zabezpieczania zasobów chmurowych (GCP), zawsze wybieraj rozwiązanie typu Managed (SCC, Secret Manager, Cloud KMS), a unikaj rozwiązań self-managed, chyba że pytanie wyraźnie wymaga dostosowania niskopoziomowego.

Haczyki egzaminacyjne (Exam Traps):
- Pułapka IAM: Pytania o uprawnienia często sugerują 'Project Owner' – zawsze szukaj 'Least Privilege' (np. 'Role: Secret Manager Secret Accessor').
- Pułapka Sieciowa: Często mylone są VPC Peering (wydajność) oraz VPN (szyfrowanie/on-premise).

Głębokie wyjaśnienie techniczne:
Rozwiązanie bazuje na GCP Shared Responsibility Model. Google zarządza bezpieczeństwem infrastruktury (Physical, Network, Host), podczas gdy administrator zarządza tożsamością (IAM), danymi (Encryption, Cloud KMS) i regułami dostępu (VPC Firewall).

Analiza i Podsumowanie (AI)

Kluczowe zagadnienia

Sugerowana odpowiedź: B

Analiza strategiczna: Pytanie o egzekwowanie skomplikowanych wymogów regulacyjnych. Assured Workloads to jedyne rozwiązanie w GCP, które łączy wymogi techniczne (residency) z operacyjnymi (lokalizacja personelu wsparcia).
