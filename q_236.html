Question 236 / 361

You are deploying regulated workloads on Google Cloud. The regulation has data residency and data access requirements. It also requires that support is provided from the same geographical location as where the data resides. What should you do?

  • A. Enable Access Transparency Logging.
  • B. Deploy Assured Workloads.
  • C. Deploy resources only to regions permitted by data residency requirements.
  • D. Use Data Access logging and Access Transparency logging to confirm that no users are accessing data from another region.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
B. Deploy Assured Workloads.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Odpowiedź B jest prawidłowa, ponieważ Assured Workloads to usługa Google Cloud stworzona specjalnie w celu automatyzacji i egzekwowania rygorystycznych wymogów regulacyjnych (takich jak suwerenność danych, suwerenność operacyjna oraz wymogi dotyczące wsparcia technicznego) bez konieczności ręcznego konfigurowania wielu skomplikowanych polityk.

Zalety wdrożenia Assured Workloads:
a. **Automatyczne wdrażanie barier (Guardrails):** Tworzy dedykowany folder w hierarchii GCP z prekonfigurowanymi politykami organizacji ograniczającymi lokalizacje zasobów (data residency).
b. **Suwerenność personelu wsparcia (Sovereign Support):** Gwarantuje, że wszelkie zgłoszenia serwisowe i interwencje wsparcia technicznego Google będą obsługiwane wyłącznie przez inżynierów spełniających wymagania geograficzne (np. zlokalizowanych w UE dla regulacji europejskich). Jest to kluczowe wymaganie postawione w pytaniu ("support is provided from the same geographical location").

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
A. Enable Access Transparency Logging.
   * Dlaczego nieprawidłowa: Access Transparency rejestruje logi z działań personelu Google na Twoich danych. Jest to usługa monitorująca i audytująca (reaktywna), ale sama w sobie nie blokuje dostępu ani nie wymusza, by wsparcie techniczne fizycznie pochodziło z określonego regionu geograficznego.
C. Deploy resources only to regions permitted by data residency requirements.
   * Dlaczego nieprawidłowa: Samo wdrożenie zasobów we właściwym regionie (np. przez dyscyplinę zespołu) nie gwarantuje spełnienia wymogów prawnych dotyczących wsparcia technicznego Google ze specyficznych lokalizacji (personel Google w USA nadal mógłby mieć dostęp do maszyn w Europie w celach wsparcia).
D. Use Data Access logging and Access Transparency logging to confirm...
   * Dlaczego nieprawidłowa: Potwierdzanie braku dostępu w logach to mechanizm detekcyjny i audytowy. Regulacje wymagają prewencyjnego zapewnienia (enforcement) zgodności, co realizuje tylko Assured Workloads.

4. Wskazówki, hinty, tips and tricks:
* Zgodność z surowymi regulacjami rządowymi/geograficznymi (FedRAMP, IL4, CJIS, EU Regions and Support) -> Zawsze wybieraj **Assured Workloads**.
* Pamiętaj o kluczowej funkcji Assured Workloads: gwarancji obsługi wsparcia technicznego (customer support) przez osoby z określonego regionu geograficznego.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
* Support from the same geographical location / Regulatory compliance folder -> Assured Workloads.
