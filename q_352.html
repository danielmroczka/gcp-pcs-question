Question 352 / 361

Your company hosts a critical web application on Google Cloud. The application is experiencing an increasing number of sophisticated layer 7 attacks, including cross-site scripting (XSS) and SQL injection attempts. You need to protect the application from these attacks while minimizing the impact on legitimate traffic and ensuring high availability. What should you do?

  • A. Implement a load balancer in front of the web application instances, and enable Adaptive Protection and throttling to mitigate the occurrence of these malicious requests.
  • B. Configure Cloud Next Generation Firewall to block known malicious IP addresses targeting /32 addresses.
  • C. Enable Google Cloud Armor's pre-configured WAF rules for OWASP Top 10 vulnerabilities at the backend service.
  • D. Configure a Cloud Armor security policy with customized and pre-configured WAF rules for OWASP Top 10 vulnerabilities at the load balancer.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

Poprawna odpowiedź: D (Configure a Cloud Armor security policy with customized and pre-configured WAF rules for OWASP Top 10 vulnerabilities at the load balancer.)

Dlaczego ta odpowiedź jest poprawna:
- Cloud Armor: To usługa WAF (Web Application Firewall) w GCP.
- "Pre-configured WAF rules for OWASP Top 10": To kluczowa funkcja Cloud Armor, która automatycznie chroni przed atakami takimi jak SQLi i XSS.
- "At the load balancer": Polityki Cloud Armor są przypisywane do backendu load balancera (HTTP(S) LB).
- Odpowiedź D jest precyzyjniejsza niż C, ponieważ wspomina o "customized AND pre-configured rules", co jest pełniejszym opisem zabezpieczeń Cloud Armor.

Analiza niepoprawnych odpowiedzi:
- A. Adaptive Protection/throttling: Chroni przed atakami DDoS, ale nie przed XSS/SQLi (do tego trzeba reguł WAF).
- B. Firewall: Chroni sieć (IP/port), a nie warstwę aplikacji (L7).
- C. At the backend service: Jest technicznie poprawna, ale D jest dokładniejsza, bo Cloud Armor definiuje politykę ("security policy"), która jest przypisana do LB.

Wskazówki i triki (Tips & Tricks):
- "Web attacks" + "XSS/SQLi" + "Robust perimeter" = Cloud Armor WAF rules (OWASP Top 10).
- Pamiętaj: WAF = WAF rules, nie Firewall Rules.

Praktyczne informacje na egzamin:
- Zapamiętaj: Google Cloud Armor chroni aplikacje webowe przed atakami na poziomie aplikacji.

Dokumentacja i linki:
- Cloud Armor WAF rules

Wskazówki egzaminacyjne (Tips & Tricks)

Reguła Egzaminacyjna (Exam Rule): 
W pytaniach typu 'Security in GCP', zawsze priorytetyzuj rozwiązania natywne (SCC, Cloud KMS, Secret Manager, VPC SC) nad rozwiązaniami typu 'third-party' lub 'self-managed', chyba że scenariusz wymaga specyficznej integracji hybrydowej.

Haczyki egzaminacyjne (Exam Traps):
- Pułapka 'Least Privilege': Egzamin często podpowiada role o szerokim zakresie (np. 'Editor' lub 'Owner') – zawsze odrzucaj je na rzecz ról predefiniowanych o najmniejszym zakresie uprawnień.
- Pułapka 'Logging vs Monitoring': Pamiętaj: Audit Logs służą do badania aktywności (Who/What/When), a Monitoring do zbierania metryk wydajnościowych.

Głębokie wyjaśnienie techniczne:
Każda architektura bezpieczeństwa w GCP powinna być projektowana w oparciu o 'Security by Default'. Oznacza to m.in. szyfrowanie w spoczynku (domyślne), tożsamość opartą na rolach (IAM) oraz pełną widoczność zapewnianą przez scentralizowane logowanie (Cloud Logging/SCC).
