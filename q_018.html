Question 18 / 361

An organization adopts Google Cloud Platform (GCP) for application hosting services and needs guidance on setting up password requirements for their Cloud Identity account. The organization has a password policy requirement that corporate employee passwords must have a minimum number of characters. Which Cloud Identity password guidelines can the organization use to inform their new requirements?

  • A. Set the minimum length for passwords to be 8 characters.
  • B. Set the minimum length for passwords to be 10 characters.
  • C. Set the minimum length for passwords to be 12 characters.
  • D. Set the minimum length for passwords to be 6 characters.
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

Poprawna odpowiedź: A (Set the minimum length for passwords to be 8 characters.)

Analiza poprawności:
Google Cloud Identity (i zintegrowany z nim Google Workspace) oferuje administratorom możliwość konfiguracji polityk haseł dla kont użytkowników. Zgodnie z najlepszymi praktykami bezpieczeństwa, zalecaną minimalną długością hasła, która zapewnia rozsądny kompromis między bezpieczeństwem a użytecznością dla pracowników korporacyjnych, jest 8 znaków. Jest to wartość często spotykana jako domyślna w standardach zgodności (compliance).

Dlaczego pozostałe są błędne:
B (10 znaków) i C (12 znaków): Choć administrator może ustawić wyższą wartość, nie są to "podstawowe wytyczne" (guidelines) definiowane jako minimalny standard przez Google.
D (6 znaków): Jest to wartość zdecydowanie zbyt niska w nowoczesnym środowisku zagrożeń (podatność na ataki typu brute-force/dictionary). Większość systemów bezpieczeństwa odrzuca hasła krótsze niż 8 znaków.

Wskazówki egzaminacyjne:
- "Minimum password length": Jeśli pytanie pyta o wytyczne Google, "magiczna liczba" to zazwyczaj 8.
- Bezpieczeństwo vs. Użyteczność: Pamiętaj, że polityki GCP/Workspace pozwalają na wymuszenie silnych haseł, ale wytyczne bezpieczeństwa to zawsze balans między tymi dwoma.

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: A

Analiza spornych kwestii (AI): Sama długość hasła to tylko jeden z elementów. Nowoczesne podejście (np. NIST) sugeruje, że ważniejsza niż częsta rotacja hasła jest jego długość (złożoność) oraz sprawdzenie, czy hasło nie wyciekło w innym serwisie (Google Cloud Identity sprawdza hasła względem znanych baz wycieków).
