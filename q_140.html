Question 140 / 361

You work for an organization in a regulated industry that has strict data protection requirements. The organization backs up their data in the cloud. To comply with data privacy regulations, this data can only be stored for a specific length of time and must be deleted after this specific period.
You want to automate the compliance with this regulation while minimizing storage costs. What should you do?

  • A. Store the data in a persistent disk, and delete the disk at expiration time.
  • B. Store the data in a Cloud Bigtable table, and set an expiration time on the column families.
  • C. Store the data in a BigQuery table, and set the table's expiration time.
  • D. Store the data in a Cloud Storage bucket, and configure the bucket's Object Lifecycle Management feature.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

Potwierdzona odpowiedź: D (Store the data in a Cloud Storage bucket, and configure the bucket's Object Lifecycle Management feature).

Wyjaśnienie:
- Cloud Storage Object Lifecycle Management: Jest to optymalne rozwiązanie dla kopii zapasowych (backups), ponieważ Cloud Storage oferuje najniższe koszty przechowywania (klasy Nearline, Coldline, Archive). Funkcja Lifecycle Management pozwala na automatyczne usuwanie obiektów po określonym czasie (warunek "Age") bez konieczności pisania skryptów, co spełnia wymaganie automatyzacji i minimalizacji kosztów.

Dlaczego pozostałe są błędne:
- A. Persistent Disk: Dyski trwałe są znacznie droższe niż Cloud Storage i nie oferują natywnej funkcji automatycznego usuwania po określonym czasie bez użycia skryptów lub dodatkowych narzędzi.
- B. Cloud Bigtable: Jest to baza danych NoSQL o wysokiej wydajności, przeznaczona do dużych obciążeń analitycznych i operacyjnych, a nie do taniego przechowywania kopii zapasowych. Chociaż ma funkcję "garbage collection" (TTL) na poziomie rodzin kolumn, koszty przechowywania danych byłyby nieproporcjonalnie wysokie.
- C. BigQuery: Jest to magazyn danych (data warehouse). Chociaż pozwala na ustawienie czasu wygaśnięcia tabeli (expiration time), jest droższy od Cloud Storage w scenariuszu czystego backupu danych binarnych lub plików logów.

Wskazówki egzaminacyjne (Tips & Tricks):
- "Minimize storage costs" + "Backups" = Zawsze myśl o Cloud Storage (GCS).
- "Automate deletion after period" = Object Lifecycle Management (GCS) lub TTL (BigQuery/Bigtable).
- Zwróć uwagę na rodzaj danych – kopie zapasowe rzadko wymagają bazy danych typu Bigtable.

Kluczowe zagadnienia do powtórzenia:
- Klasy przechowywania Cloud Storage (Standard, Nearline, Coldline, Archive).
- Object Lifecycle Management i dostępne warunki (Age, CreatedBefore, IsLive).
- Retencja danych i polityki usuwania w różnych usługach GCP.
