Question 1 / 361

Your team needs to make sure that a Compute Engine instance does not have access to the internet or to any Google APIs or services. Which two settings must remain disabled to meet these requirements? (Choose two.)

  • A. Public IP
  • B. IP Forwarding
  • C. Private Google Access
  • D. Static routes
Show Suggested Answer Hide Answer
Suggested Answer: AC

Wyjaśnienie

**Potwierdzona odpowiedź: AC**

**Reguła Egzaminacyjna (Exam Rule):**
Jeśli widzisz pytanie o izolację instancji Compute Engine zarówno od publicznego Internetu, JAK I od usług Google API, zawsze wybierz parę: {Public IP disabled, Private Google Access disabled}. Public IP zapewnia dostęp do Internetu, a Private Google Access (nawet bez publicznego IP) zapewnia instancji dostęp do publicznych punktów końcowych API Google poprzez wewnętrzną sieć Google.

**Haczyki egzaminacyjne (Exam Traps):**
- Wybór "IP Forwarding": Jest to funkcja potrzebna, gdy instancja działa jako brama (np. VPN lub NAT), ale nie wpływa bezpośrednio na dostęp do Google API.
- Zakładanie, że brak publicznego IP wystarczy: Bez wyłączonego Private Google Access, instancja nadal może "sięgnąć" do API Google.

**Głębokie wyjaśnienie techniczne:**
W modelu współdzielonej odpowiedzialności GCP, konfiguracja sieci VPC jest po stronie klienta. 
1. **Public IP**: Wyłączenie go odcina bezpośredni dostęp do Internetu (egress do publicznych IP).
2. **Private Google Access (PGA)**: Ta funkcja umożliwia instancjom bez publicznych adresów IP komunikację z API Google poprzez wewnętrzną sieć Google. Wyłączenie PGA na poziomie podsieci (subnet) wymusza, aby ruch do API Google nie opuszczał prywatnej sieci w sposób niekontrolowany.

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: AC

Analiza spornych kwestii (AI): Głównym punktem debaty w sieci jest to, czy wyłączenie PGA wystarczy. Eksperci zauważają, że w nowoczesnych sieciach GCP istnieje również Private Service Connect (PSC), który mógłby być trzecią drogą wyjścia, ale nie ma go w opcjach. Dlatego AC pozostaje jedyną poprawną odpowiedzią w ramach dostępnego zestawu. Pułapką jest tu opcja D – trasy statyczne są potrzebne do komunikacji wewnątrz VPC, ich wyłączenie to 'przysłowiowe spalenie mostu', a nie precyzyjna kontrola dostępu.
