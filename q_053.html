Question 53 / 361

A customer deployed an application on Compute Engine that takes advantage of the elastic nature of cloud computing. How can you work with Infrastructure Operations Engineers to best ensure that Windows Compute Engine VMs are up to date with all the latest OS patches?

  • A. Build new base images when patches are available, and use a CI/CD pipeline to rebuild VMs, deploying incrementally.
  • B. Federate a Domain Controller into Compute Engine, and roll out weekly patches via Group Policy Object.
  • C. Use Deployment Manager to provision updated VMs into new serving Instance Groups (IGs).
  • D. Reboot all VMs during the weekly maintenance window and allow the StartUp Script to download the latest patches from the internet.
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

Potwierdzona odpowiedź: A

Reguła Egzaminacyjna (Exam Rule):
W chmurze GCP należy dążyć do Immutable Infrastructure (infrastruktury niezmiennej). Zamiast patchować działające instancje ("in-place patching"), należy budować nowe, zaktualizowane obrazy bazowe ("Golden Images") i wdrażać je za pomocą potoków CI/CD.

Haczyki egzaminacyjne (Exam Traps):
- Metody on-premises: Opcje B (GPO) oraz D (StartUp Script patching) to techniki stosowane w tradycyjnych centrach danych. W środowisku elastycznym (autoscaling) są nieefektywne, zawodne i wydłużają czas startu instancji.
- Zmylenie narzędziami: Opcja C sugeruje tylko Deployment Manager, który jest narzędziem do IaC (Infrastructure as Code), ale samo provisionowanie to za mało bez procesu automatyzacji budowania i testowania obrazów.

Głębokie wyjaśnienie techniczne:
Budowa zaktualizowanego obrazu zapewnia:
1. Powtarzalność: Każda nowa instancja jest identyczna i zawiera wszystkie poprawki.
2. Szybkość skalowania: Instancje nie muszą tracić czasu na pobieranie poprawek przy starcie.
3. Bezpieczeństwo: Eliminuje "configuration drift" – stan, w którym serwery mają różne wersje patchy, co jest częstym powodem podatności.
W praktyce wykorzystuje się narzędzia takie jak HashiCorp Packer do tworzenia obrazów oraz MIGs Rolling Updates do automatycznej zamiany instancji na nową wersję.
