Question 350 / 361

Your company is deploying a large number of containerized applications to GKE. The existing CI/CD pipeline uses Cloud Build to construct container images, transfers the images to Artifact Registry, and then deploys the images to GKE. You need to ensure that only images that have passed vulnerability scanning and meet specific corporate policies are allowed to be deployed. The process needs to be automated and integrated into the existing CI/CD pipeline. What should you do?

  • A. Configure a policy in Binary Authorization to use Artifact Analysis vulnerability scanning to only allow images that pass the scan to deploy to your GKE clusters.
  • B. Enable Artifact Analysis vulnerability scanning and regularly scan images in Artifact Registry. Remove any images that do not meet the vulnerability requirements before deployment.
  • C. Implement a custom script in the Cloud Build pipeline that uses a third-party vulnerability scanning tool. Fail the build if vulnerabilities are found.
  • D. Configure GKE to use only images from a specific, trusted Artifact Registry repository. Manually inspect all images before pushing them to this repository.
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

Poprawna odpowiedź: A (Configure a policy in Binary Authorization to use Artifact Analysis vulnerability scanning to only allow images that pass the scan to deploy to your GKE clusters.)

Dlaczego ta odpowiedź jest poprawna:
- Binary Authorization + Artifact Analysis: To standard w GKE do automatycznego sprawdzania (enforcement), czy obraz posiada atestację (attestation) z pozytywnego skanowania podatności (Artifact Analysis).
- "Automated" + "Integrated": Binary Auth wpięte w CI/CD to natywne rozwiązanie dla tego wymagania.

Analiza niepoprawnych odpowiedzi:
- B. Manual removal: Nie jest to automatyczne (wymaga manualnej interwencji).
- C. Custom script: Jest to podejście "niemanaged" (wymaga utrzymania kodu, podatne na błędy).
- D. Manual inspection: Bardzo pracochłonne, nie skaluje się dla "large number of applications".

Wskazówki i triki (Tips & Tricks):
- "Only images that passed vulnerability scanning" + "Automated" + "GKE" = Binary Authorization + Artifact Analysis.

Praktyczne informacje na egzamin:
- Zapamiętaj: Binary Authorization to brama, która weryfikuje polityki bezpieczeństwa *zanim* kontener wystartuje w klastrze.

Kluczowe zagadnienia

Sugerowana odpowiedź: A

Analiza strategiczna: Pytanie o automatyzację bezpieczeństwa w procesie CI/CD i GKE. Binary Authorization jest natywnym rozwiązaniem GCP do wymuszania polityk bezpieczeństwa na poziomie obrazów kontenerowych przed ich uruchomieniem w klastrze.
