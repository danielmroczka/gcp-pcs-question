Question 31 / 361

An organization is starting to move its infrastructure from its on-premises environment to Google Cloud Platform (GCP). The first step the organization wants to take is to migrate its current data backup and disaster recovery solutions to GCP for later analysis. The organization's production environment will remain on-premises for an indefinite time. The organization wants a scalable and cost-efficient solution.
Which GCP solution should the organization use?

  • A. BigQuery using a data pipeline job with continuous updates
  • B. Cloud Storage using a scheduled task and gsutil
  • C. Compute Engine Virtual Machines using Persistent Disk
  • D. Cloud Datastore using regularly scheduled batch upload jobs
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

**Poprawna odpowiedź: B**

**1. Kompleksowe wyjaśnienie poprawnej odpowiedzi:**
Pierwszym krokiem migracji jest stworzenie skalowalnego i niedrogiego środowiska do przechowywania kopii zapasowych i danych odzyskiwania katastroficznego (DR) z serwerowni lokalnej:
- **Cloud Storage z użyciem zaplanowanego zadania i narzędzia gsutil (B):** Cloud Storage to wysoce skalowalna, obiektowa pamięć masowa o niemal nieograniczonej pojemności. Klasy przechowywania (np. Coldline lub Archive) zapewniają minimalne koszty dla rzadko używanych danych DR. Narzędzie `gsutil` pozwala na łatwe skryptowanie i automatyzację przesyłania kopii zapasowych z lokalnych serwerów.

**2. Wyjaśnienie niepoprawnych odpowiedzi:**
- **A. BigQuery:** Jest to hurtownia danych przeznaczona do analiz analitycznych SQL. Przechowywanie tam surowych kopii zapasowych (np. obrazów dysków, backupów baz) jest nieefektywne i niezwykle kosztowne.
- **C. Compute Engine VM z Persistent Disk:** Wymagałoby to ciągłego działania maszyn wirtualnych i opłacania stałej alokacji dysków SSD/HDD, co jest rozwiązaniem drogim i słabo skalowalnym w porównaniu do obiektowego Cloud Storage.
- **D. Cloud Datastore (obecnie Firestore):** To baza danych NoSQL dla małych obiektów/dokumentów, całkowicie niedostosowana do przechowywania dużych plików kopii zapasowych.

**3. Wskazówki i pułapki egzaminacyjne (Tips & Tricks):**
- Dla kopii zapasowych (backups) i archiwizacji danych (disaster recovery) w chmurze najtańszym i najprostszym wyborem jest zawsze **Cloud Storage** z odpowiednią klasą dostępu (Nearline/Coldline/Archive).
- Narzędzie `gsutil` to standardowe narzędzie CLI do zarządzania obiektami w Cloud Storage.

**4. Reguły wyboru odpowiedzi:**
- Przechowywanie kopii zapasowych (DR) -> Cloud Storage.

**5. Dodatkowe źródła:**
- Cloud Storage classes: https://cloud.google.com/storage/docs/storage-classes

Analiza (AI)

Sugerowana odpowiedź: B

Cloud Storage pozostaje standardowym wyborem dla backupu on-premises. Odpowiedzi A, C, D są nieadekwatne technologicznie (zastosowanie baz danych do plików, koszty dysków blokowych).
