Question 24 / 361

A company's application is deployed with a user-managed Service Account key. You want to use Google-recommended practices to rotate the key.
What should you do?

  • A. Open Cloud Shell and run gcloud iam service-accounts enable-auto-rotate --iam-account=IAM_ACCOUNT.
  • B. Open Cloud Shell and run gcloud iam service-accounts keys rotate --iam-account=IAM_ACCOUNT --key=NEW_KEY.
  • C. Create a new key, and use the new key in the application. Delete the old key from the Service Account.
  • D. Create a new key, and use the new key in the application. Store the old key on the system as a backup key.
Show Suggested Answer Hide Answer
Suggested Answer: C

Wyjaśnienie

**Potwierdzona odpowiedź: C**

**Reguła Egzaminacyjna (Exam Rule):**
Klucze kont serwisowych (Service Account Keys) są długowiecznymi poświadczeniami. Najlepszą praktyką rotacji jest stworzenie nowego klucza, zaktualizowanie aplikacji, a następnie usunięcie starego.

**Haczyki egzaminacyjne (Exam Traps):**
- A, B: Nie istnieje w gcloud polecenie enable-auto-rotate ani keys rotate (bezpośrednia zmiana).
- D: Przechowywanie "starego klucza jako backup" jest błędem bezpieczeństwa, ponieważ klucz pozostaje aktywny i może być wykorzystany przez osobę niepowołaną.

**Głębokie wyjaśnienie techniczne:**
W modelu współdzielonej odpowiedzialności, klient zarządza dostępem i poświadczeniami (IAM). Google zaleca unikanie używania kluczy kont serwisowych na rzecz Workload Identity lub innych metod autentykacji (np. OAuth 2.0). Jeśli użycie kluczy jest konieczne, klient jest odpowiedzialny za ich ręczną rotację w celu ograniczenia wpływu ewentualnego wycieku klucza.

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: C

Analiza spornych kwestii (AI): Współczesne zalecenia bezpieczeństwa Google sugerują całkowite unikanie kluczy JSON (Service Account Keys) na rzecz tożsamości instancji lub Workload Identity Federation, co eliminuje problem rotacji. Jeśli jednak musisz ich używać, procedura opisana w punkcie C jest jedynym poprawnym i wspieranym sposobem na ich odświeżenie.
