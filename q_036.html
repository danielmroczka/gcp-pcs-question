Question 36 / 361

A retail customer allows users to upload comments and product reviews. The customer needs to make sure the text does not include sensitive data before the comments or reviews are published.
Which Google Cloud Service should be used to achieve this?

  • A. Cloud Key Management Service
  • B. Cloud Data Loss Prevention API
  • C. BigQuery
  • D. Web Security Scanner
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

**Poprawna odpowiedź: B**

**1. Kompleksowe wyjaśnienie poprawnej odpowiedzi:**
Klient musi skanować tekst komentarzy i recenzji przed publikacją, aby upewnić się, że nie zawierają one danych wrażliwych (PII, takich jak e-maile, telefony, dane finansowe):
- **Cloud Data Loss Prevention (DLP) API (B):** Jest to usługa zaprojektowana specjalnie do automatycznego wykrywania, klasyfikowania i maskowania (deidentyfikacji) danych wrażliwych w tekstach i plikach. DLP API udostępnia szybkie metody synchroniczne, które aplikacja może wywołać w locie przed zapisaniem komentarza do bazy danych.

**2. Wyjaśnienie niepoprawnych odpowiedzi:**
- **A. Cloud KMS:** Służy do kryptograficznego szyfrowania/odszyfrowywania danych, nie analizuje ich zawartości pod kątem obecności danych osobowych.
- **C. BigQuery:** To analityczna baza danych. Zapisanie tam nieoczyszczonych komentarzy i dopiero późniejsza analiza nie zapobiega opublikowaniu danych wrażliwych na stronie www.
- **D. Web Security Scanner:** Służy do wykrywania podatności w kodzie i konfiguracji aplikacji webowej (np. SQLi, XSS), nie służy do cenzurowania i ochrony danych wrażliwych przesyłanych przez użytkowników w formularzach.

**3. Wskazówki i pułapki egzaminacyjne (Tips & Tricks):**
- Jeśli celem jest identyfikacja lub usunięcie danych osobowych / wrażliwych (PII, PHI, dane kart) z nieustrukturyzowanego tekstu przed jego zapisaniem/publikacją -> Zawsze wybieraj **Cloud DLP API**.
- DLP działa w czasie rzeczywistym przez API.

**4. Reguły wyboru odpowiedzi:**
- Wykrywanie i usuwanie danych osobowych w tekście -> Cloud DLP API.

**5. Dodatkowe źródła:**
- Cloud DLP API Documentation: https://cloud.google.com/dlp/docs

Analiza i Wyjaśnienie

Sugerowana odpowiedź: B

Analiza spornych kwestii (AI): DLP może działać w trybie 'Inspect' (znajdź) lub 'De-identify' (zamaskuj/zastąp). W tym scenariuszu aplikacja wysyłałaby recenzję do API DLP przed zapisem w bazie, co pozwala na bezpieczne "przecedzenie" treści.

Wyjaśnienie Audytowe

Reguła Egzaminacyjna (Exam Rule):
Pamiętaj, że w egzaminie Professional Cloud Security Engineer kluczowe jest wybieranie rozwiązań najmniej uprzywilejowanych (Principle of Least Privilege), zoptymalizowanych kosztowo i spełniających wymogi compliancy (np. CMEK, Data Loss Prevention).

Haczyki egzaminacyjne (Exam Traps):
- Wybór rozwiązań, które wydają się wygodne, ale nie spełniają wymogów bezpieczeństwa (np. zbyt szerokie uprawnienia IAM).
- Mylenie usług: np. Cloud Armor (WAF) z Cloud IAP (Identity-Aware Proxy).

Głębokie wyjaśnienie techniczne (GCP Professional Cloud Security Engineer):
W każdym pytaniu analizuj warstwy: IAM (dostęp), Encryption (at rest/in transit), Logging/Monitoring (Audit Logs, Cloud Logging, Security Command Center) oraz Networking (VPC Service Controls, Firewall Rules). GCP kładzie duży nacisk na współdzieloną odpowiedzialność (Shared Responsibility Model) - klient odpowiada za konfigurację zabezpieczeń wewnątrz usług chmurowych.
