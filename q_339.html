Question 339 / 361

Your company is migrating a three-tier web application to Google Cloud. The application consists of a web frontend, an application backend, and a database. Due to regulatory requirements and existing on-premises infrastructure dependencies, you need to implement a hybrid cloud architecture. The web frontend will be hosted on Google Cloud, while the application backend and the database will remain on-premises initially. You need to ensure secure and efficient communication between the cloud-based frontend and the on-premises backend and database, minimizing latency and maximizing availability. What should you do?

  • A. Establish a Dedicated Interconnect connection between the Google Cloud VPC network and the on-premises network. Configure firewall rules to allow communication between the three tiers.
  • B. Establish a direct internet connection between the Google Cloud VPC network hosting the web frontend and the on-premises network that hosts the backend and database. Configure firewall rules to allow communication between the three tiers.
  • C. Replicate the on-premises backend and database to Google Cloud. Use a hybrid connectivity network endpoint group for the primary. Backup to the zonal network endpoint group.
  • D. Use a highly-available Cloud VPN connection over the public internet to connect the Google Cloud VPC network to the on-premises network.
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

✅ PRAWIDŁOWA ODPOWIEDŹ: A

Prawidłowa odpowiedź: A – Establish a Dedicated Interconnect connection between the Google Cloud VPC network and the on-premises network.

DLACZEGO A JEST PRAWIDŁOWE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Pytanie: regulowane wymagania + "existing network infrastructure" + 3-tier app (frontend w GCP, backend i DB on-premises). Dedicated Interconnect:
- Połączenie fizyczne dedykowane (prywatne, nie przez Internet).
- Spełnia wymagania regulacyjne (dane nie przechodzą przez publiczny Internet).
- Wysoka przepustowość (10Gbps-100Gbps).
- Niskie opóźnienia.
- SLA 99.99% (dla redundantnego).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO INNE OPCJE SĄ BŁĘDNE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
B. ❌ Direct Internet connection = dane przechodzą przez publiczny Internet. Naruszenie wymagań regulacyjnych.
C. ❌ Replikacja backendu/DB do GCP + hybrid connectivity = zmiana architektury, nie rozwiązanie hybrid connectivity dla istniejącej aplikacji.
D. ❌ Cloud VPN przez publiczny Internet = szyfrowane, ale dane przechodzą przez publiczny Internet. Dla ścisłych wymagań regulacyjnych, Interconnect jest preferowany.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WSKAZÓWKI EGZAMINACYJNE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• "Regulatory requirements" + "on-premises" + "private connection" = Dedicated Interconnect.
• Cloud VPN = przez Internet (szyfrowane), Interconnect = nie przez Internet.
• Dedicated Interconnect > Partner Interconnect (Dedicated = bezpośrednie).
• Kolocacja wymagana dla Dedicated Interconnect.

REGUŁY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Regulowane + prywatne połączenie = Dedicated/Partner Interconnect (nie VPN).
• VPN = szyfrowany tunnel przez Internet (nie "private network").
