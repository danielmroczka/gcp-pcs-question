Question 162 / 361

Which Identity-Aware Proxy role should you grant to an Identity and Access Management (IAM) user to access HTTPS resources?

  • A. Security Reviewer
  • B. IAP-Secured Tunnel User
  • C. IAP-Secured Web App User
  • D. Service Broker Operator
Show Suggested Answer Hide Answer
Suggested Answer: C

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
C. IAP-Secured Web App User

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Pytanie dotyczy wskazania roli IAM niezbędnej do uzyskania dostępu do zasobów HTTPS (np. aplikacji webowych) chronionych przez Identity-Aware Proxy (IAP):
- Rola `roles/iap.httpsResourceAccessor` (IAP-Secured Web App User / Użytkownik zabezpieczonej aplikacji internetowej IAP) jest dedykowaną rolą IAM, która pozwala użytkownikom na autoryzację i dostęp do aplikacji HTTPS zabezpieczonych za pomocą IAP (takich jak App Engine, usługi GKE lub Compute Engine wystawione za Load Balancerem L7).

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- A. Security Reviewer: Jest to rola przeznaczona do audytu ustawień bezpieczeństwa w konsoli GCP, nie nadaje uprawnień dostępu do aplikacji biznesowych chronionych przez IAP.
- B. IAP-Secured Tunnel User (`roles/iap.tunnelResourceAccessor`): Ta rola jest używana do tunelowania ruchu TCP (np. protokołów SSH na porcie 22 lub RDP na porcie 3389) do maszyn wirtualnych bez publicznych adresów IP. Nie służy do uzyskiwania dostępu do aplikacji HTTP/HTTPS.
- D. Service Broker Operator: Jest to rola powiązana z integracją usług zewnętrznych, nie ma związku z autoryzacją użytkowników IAP do aplikacji webowych.

4. Wskazówki, hinty, tips and tricks:
- Zapamiętaj dwie główne role IAP na egzamin:
  - Dostęp do stron WWW (HTTPS) -> **IAP-Secured Web App User** (`httpsResourceAccessor`).
  - Dostęp do konsoli/tunelu (SSH/RDP/TCP) -> **IAP-Secured Tunnel User** (`tunnelResourceAccessor`).

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Dostęp IAP do zasobów HTTPS / aplikacji internetowych -> IAP-Secured Web App User.

6. Dodatkowe źródła i dokumentacja:
