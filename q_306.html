Question 306 / 361

You must ensure that the keys used for at-rest encryption of your data are compliant with your organization's security controls. One security control mandates that keys get rotated every 90 days. You must implement an effective detection strategy to validate if keys are rotated as required. What should you do?

  • A. Analyze the crypto key versions of the keys by using data from Cloud Asset Inventory. If an active key is older than 90 days, send an alert message through your incident notification channel.
  • B. Assess the keys in the Cloud Key Management Service by implementing code in Cloud Run. If a key is not rotated after 90 days, raise a finding in Security Command Center.
  • C. Define a metric that checks for timely key updates by using Cloud Logging. If a key is not rotated after 90 days, send an alert message through your incident notification channel.
  • D. Identify keys that have not been rotated by using Security Health Analytics. If a key is not rotated after 90 days, a finding in Security Command Center is raised.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

✅ PRAWIDŁOWA ODPOWIEDŹ: D

Prawidłowa odpowiedź: D – Identify keys that have not been rotated by using Security Health Analytics. If keys are non-compliant, trigger a Cloud Run function to rotate them.

DLACZEGO D JEST PRAWIDŁOWE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Security Health Analytics (część SCC) automatycznie sprawdza klucze KMS pod kątem zgodności z politykami bezpieczeństwa, w tym rotacji kluczy. Połączenie z Cloud Run function do automatycznej rotacji tworzy kompletny, zautomatyzowany cykl: wykrycie → naprawa. To natywne podejście GCP.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO INNE OPCJE SĄ BŁĘDNE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. ❌ Cloud Asset Inventory może pokazać metadane kluczy, ale nie analizuje compliance i wymaga custom skryptów do detekcji problemu.
B. ❌ Cloud Functions sprawdzające Cloud KMS API = custom rozwiązanie wymagające pisania i utrzymania kodu. Opcja D jest natywna i prostsza.
C. ❌ Cloud Logging metryki mogą wykryć brak rotacji, ale wymagają własnej logiki. SHA jest bardziej bezpośredni i wbudowany w SCC.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WSKAZÓWKI EGZAMINACYJNE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• KMS key rotation compliance = Security Health Analytics (SCC).
• SHA znajdzie nieskonfigurowaną rotację automatycznie bez pisania kodu.
• Pytania o "compliance klucza" = myśl SCC/SHA jako pierwsza opcja.
