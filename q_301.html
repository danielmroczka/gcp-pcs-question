Question 301 / 361

Your organization is implementing separation of duties in a Google Cloud project. A group of developers must deploy new code, but cannot have permission to change network firewall rules. What should you do?

  • A. Assign the network administrator IAM role to all developers. Tell developers not to change firewall settings.
  • B. Use Access Context Manager to create conditions that allow only authorized administrators to change firewall rules based on attributes such as IP address or device security posture.
  • C. Create and assign two custom IAM roles. Assign the deployer role to control Compute Engine and deployment-related permissions. Assign the network administrator role to manage firewall permissions.
  • D. Grant the editor IAM role to the developer group. Explicitly negate any firewall modification permissions by using IAM deny policies.
Show Suggested Answer Hide Answer
Suggested Answer: C

Wyjaśnienie

✅ PRAWIDŁOWA ODPOWIEDŹ: B

Prawidłowa odpowiedź: B – Use VPC Service Controls to enforce restrictions on access to and from Google-managed services within a perimeter.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO B JEST PRAWIDŁOWE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
VPC Service Controls (VPC SC) tworzy "perymetr bezpieczeństwa" wokół usług Google (BigQuery, Cloud Storage, itp.) i zapobiega:
- Eksfiltracji danych poza perymetr.
- Dostępowi do danych z niezaufanych sieci/projektów.
- To jedyne narzędzie GCP, które faktycznie zapobiega eksfiltracji danych z zarządzanych usług.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO INNE OPCJE SĄ BŁĘDNE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. ❌ Firewall rules dotyczą ruchu sieciowego do/z VM, nie zarządzają dostępem do Google-managed services (np. BigQuery API).
C. ❌ Cloud DLP wykrywa i maskuje dane wrażliwe, ale nie blokuje eksfiltracji na poziomie sieci.
D. ❌ IAM kontroluje kto ma dostęp do zasobów, ale nie tworzy perimetru zapobiegającego eksfiltracji.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WSKAZÓWKI EGZAMINACYJNE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• "Prevent data exfiltration from managed services" = VPC Service Controls.
• VPC SC ≠ firewall rules (firewalls = VM traffic, VPC SC = API-level perimeter).
• Kluczowe słowa: "perimeter", "Google-managed services", "data exfiltration".

• Firewall rules → ruch do/z VM (nie do API Google).

Analiza i Podsumowanie (AI)

Kluczowe zagadnienia

Sugerowana odpowiedź: C

Analiza strategiczna: To pytanie testuje Twoją zdolność do projektowania bezpiecznych procesów administracyjnych. W chmurze uprawnienia są "wszędobylskie". Twoim zadaniem jako inżyniera bezpieczeństwa jest ich "przycinanie" (pruning), aby każda osoba miała tylko tyle uprawnień, ile jest jej niezbędne do wykonania pracy – ani mniej, ani więcej.
