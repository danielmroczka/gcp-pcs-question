Question 181 / 361

Your organization operates Virtual Machines (VMs) with only private IPs in the Virtual Private Cloud (VPC) with internet access through Cloud NAT. Everyday, you must patch all VMs with critical OS updates and provide summary reports. What should you do?

  • A. Validate that the egress firewall rules allow any outgoing traffic. Log in to each VM and execute OS specific update commands. Configure the Cloud Scheduler job to update with critical patches daily for daily updates.
  • B. Copy the latest patches to the Cloud Storage bucket. Log in to each VM, download the patches from the bucket, and install them.
  • C. Assign public IPs to VMs. Validate that the egress firewall rules allow any outgoing traffic. Log in to each VM, and configure a daily cron job to enable for OS updates at night during low activity periods.
  • D. Ensure that VM Manager is installed and running on the VMs. In the OS patch management service, configure the patch jobs to update with critical patches daily.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
D. Ensure that VM Manager is installed and running on the VMs. In the OS patch management service, configure the patch jobs to update with critical patches daily.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Firma musi codziennie instalować krytyczne poprawki systemu operacyjnego (OS patching) na maszynach prywatnych (za bramą Cloud NAT) oraz generować raporty podsumowujące:
- **VM Manager** to zestaw zintegrowanych narzędzi GCP służących do zarządzania systemami operacyjnymi na instancjach Compute Engine.
- Moduł **OS patch management** (zarządzanie poprawkami) pozwala na pełne zautomatyzowanie procesu wdrażania poprawek. Zamiast pisać skrypty, administrator definiuje zadania aktualizacji (Patch Jobs) bezpośrednio w konsoli chmury, wskazując harmonogram (np. codziennie) oraz typ poprawek (np. krytyczne). VM Manager dba o pobranie poprawek przez Cloud NAT, ich instalację oraz automatycznie generuje raporty zgodności, co całkowicie eliminuje narzut operacyjny.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- A. Ręczne logowanie się i uruchamianie aktualizacji: Generuje gigantyczny narzut operacyjny dla administratorów przy zarządzaniu wieloma maszynami i uniemożliwia spójne generowanie raportów audytowych.
- B. Pobieranie poprawek z kubełka Cloud Storage: Wymaga ręcznego pobierania aktualizacji z repozytoriów dystrybucyjnych, wrzucania ich do kubełka i pisania własnych skryptów instalacyjnych na maszynach VM, co jest wysoce skomplikowane i nieefektywne.
- C. Przypisywanie publicznych adresów IP maszynom wirtualnym: Jest to poważne naruszenie zasad bezpieczeństwa, wystawiające prywatne maszyny bezpośrednio na zagrożenia z internetu.

4. Wskazówki, hinty, tips and tricks:
- Do centralnego, automatycznego aktualizowania systemów operacyjnych maszyn wirtualnych (patching) i generowania raportów w GCP służy usługa **VM Manager** (wymagająca zainstalowania agenta OS Config na instancjach).

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Codzienne instalowanie krytycznych łatek (patching) + raportowanie -> VM Manager (OS patch management).
