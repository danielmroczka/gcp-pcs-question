Question 259 / 361

Your team maintains 1PB of sensitive data within BigQuery that contains personally identifiable information (PII). You need to provide access to this dataset to another team within your organization for analysis purposes. You must share the BigQuery dataset with the other team while protecting the PII. What should you do?

  • A. Utilize BigQuery's row-level access policies to mask PII columns based on the other team's user identities.
  • B. Export the BigQuery dataset to Cloud Storage. Create a VPC Service Control perimeter and allow only their team's project access to the bucket.
  • C. Implement data pseudonymization techniques to replace the PII fields with non-identifiable values. Grant the other team access to the pseudonymized dataset.
  • D. Create a filtered copy of the dataset and replace the sensitive data with hash values in a separate project. Grant the other team access to this new project.
Show Suggested Answer
Suggested Answer: A

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
C. Implement data pseudonymization techniques to replace the PII fields with non-identifiable values. Grant the other team access to the pseudonymized dataset.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Odpowiedź C jest prawidłowa, ponieważ pseudonimizacja danych (data pseudonymization) pozwala na pełną ochronę prywatności klientów (PII) przed zespołem analitycznym, jednocześnie umożliwiając im wykonywanie zaawansowanych analiz statystycznych i korelacji na pełnym zbiorze danych (1 PB).

Dlaczego to najlepsza metoda:
a. **Zachowanie użyteczności danych:** Zastąpienie wrażliwych identyfikatorów (np. nazwisk, PESELi) unikalnymi pseudonimami (np. wygenerowanymi tokenami) pozwala analitykom na śledzenie zachowań unikalnych użytkowników w czasie i łączenie rekordów (np. ten sam klient wykonał operacje A i B), ponieważ pseudonimy są spójne.
b. **Bezpieczeństwo (PII Protection):** Zespół analityczny nie ma możliwości bezpośredniego zidentyfikowania osób fizycznych, ponieważ nie posiada klucza dekodującego (tabeli mapowania), który pozostaje bezpiecznie w zespole źródłowym. Jest to zalecana praktyka w ramach GDPR.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
A. Utilize BigQuery's row-level access policies to mask PII columns based on the other team's user identities.
   * Dlaczego nieprawidłowa: Sformułowanie to zawiera błąd techniczny. W BigQuery zasady dostępu na poziomie wiersza (row-level access policies) służą do filtrowania i ukrywania *wierszy* (rekordów) spełniających określone kryteria. Do ukrywania lub maskowania *kolumn* (takich jak kolumny PII) służą zasady na poziomie kolumn (column-level security) lub dynamiczne maskowanie danych (dynamic data masking), a nie row-level policies.
B. Export the BigQuery dataset to Cloud Storage. Create a VPC Service Control perimeter...
   * Dlaczego nieprawidłowa: Eksport 1 petabajta danych do Cloud Storage generuje olbrzymie koszty przechowywania i transferu oraz narzut operacyjny. Perymetr VPC SC chroni przed eksfiltracją sieciową, ale nie maskuje i nie usuwa danych PII z plików – zespół analityczny nadal miałby wgląd w surowe, niezaszyfrowane dane PII wewnątrz perymetru.
D. Create a filtered copy of the dataset and replace the sensitive data with hash values in a separate project...
   * Dlaczego nieprawidłowa: Tworzenie fizycznej kopii zbioru o rozmiarze 1 PB w innym projekcie podwaja koszty przechowywania danych w BigQuery (kolejny 1 PB danych) oraz wymaga ciągłej synchronizacji zmian w tle, co jest nieefektywne w porównaniu z udostępnieniem jednego pseudonimizowanego zbioru/widoku (opcja C).

4. Wskazówki, hinty, tips and tricks:
* Aby bezpiecznie udostępnić duże zbiory danych analitycznych bez ujawniania PII -> Stosuj **pseudonimizację (pseudonymization)** lub **dynamiczne maskowanie danych (dynamic data masking)**.
* Pamiętaj o różnicach technicznych w BigQuery:
  - Row-level security = ukrywanie wierszy (np. tylko klienci z Polski).
  - Column-level security / Data Masking = ukrywanie/maskowanie kolumn (np. zamiana cyfr PESEL na 'X').

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
* Share BigQuery dataset containing PII + protect PII -> Implement data pseudonymization techniques.
