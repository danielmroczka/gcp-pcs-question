Question 182 / 361

For compliance reporting purposes, the internal audit department needs you to provide the list of virtual machines (VMs) that have critical operating system (OS) security updates available, but not installed. You must provide this list every six months, and you want to perform this task quickly.
What should you do?

  • A. Run a Security Command Center security scan on all VMs to extract a list of VMs with critical OS vulnerabilities every six months.
  • B. Run a gcloud CLI command from the Command Line Interface (CLI) to extract the VM's OS version information every six months.
  • C. Ensure that the Cloud Logging agent is installed on all VMs, and extract the OS last update log date every six months.
  • D. Ensure the OS Config agent is installed on all VMs and extract the patch status dashboard every six months.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
D. Ensure the OS Config agent is installed on all VMs and extract the patch status dashboard every six months.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Dla celów audytu zgodności należy szybko i cyklicznie (co 6 miesięcy) generować listę maszyn wirtualnych, które mają dostępne, ale niezainstalowane krytyczne poprawki bezpieczeństwa:
- Usługa **VM Manager** (wykorzystująca agenta **OS Config** zainstalowanego na maszynach) zbiera informacje o stanie pakietów systemowych na maszynach wirtualnych.
- Pulpit nawigacyjny stanu poprawek (Patch Status Dashboard) lub funkcja OS Inventory w konsoli Google Cloud pozwala na natychmiastowy wgląd w stan zgodności maszyn (wyświetla listę VM, które wymagają zainstalowania łatek). Wyciągnięcie raportu zajmuje kilka sekund, co w pełni spełnia wymaganie szybkości wykonania zadania.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- A. Uruchomienie skanowania Security Command Center (SCC): SCC skanuje konfigurację chmury pod kątem misconfigurations (np. publiczne porty, uprawnienia IAM), ale nie wykonuje wewnętrznej analizy menedżera pakietów systemu operacyjnego (apt/yum) w poszukiwaniu dostępnych aktualizacji w locie.
- B. Pobieranie wersji systemu za pomocą gcloud CLI: Sam numer wersji systemu operacyjnego (np. Ubuntu 20.04.1) nie informuje o tym, jakie konkretnie krytyczne pakiety bezpieczeństwa są w tej chwili dostępne w repozytoriach do zainstalowania.
- C. Analiza logów agenta Cloud Logging: Agent logów przesyła surowe zdarzenia systemowe, ale nie generuje zagregowanych raportów o stanie brakujących poprawek bezpieczeństwa w menedżerze pakietów OS.

4. Wskazówki, hinty, tips and tricks:
- Wszelkie raporty o stanie aktualizacji maszyn, brakujących łatek bezpieczeństwa (missing patches) oraz utylizacji wersji systemów operacyjnych VM w GCP wymagają użycia agenta **OS Config** (VM Manager).

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Lista VM z brakującymi łatkami bezpieczeństwa -> Agent OS Config / VM Manager.

6. Dodatkowe źródła i dokumentacja:
- View patch compliance status: https://cloud.google.com/compute/docs/os-patch-management/view-patch-compliance
