Question 182 / 361

For compliance reporting purposes, the internal audit department needs you to provide the list of virtual machines (VMs) that have critical operating system (OS) security updates available, but not installed. You must provide this list every six months, and you want to perform this task quickly.
What should you do?

  • A. Run a Security Command Center security scan on all VMs to extract a list of VMs with critical OS vulnerabilities every six months.
  • B. Run a gcloud CLI command from the Command Line Interface (CLI) to extract the VM's OS version information every six months.
  • C. Ensure that the Cloud Logging agent is installed on all VMs, and extract the OS last update log date every six months.
  • D. Ensure the OS Config agent is installed on all VMs and extract the patch status dashboard every six months.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

Poprawna odpowiedź: D (Ensure the OS Config agent is installed on all VMs and extract the patch status dashboard every six months)

Dlaczego ta odpowiedź jest poprawna:
- OS Config Agent: Jest to kluczowy komponent usługi VM Manager. Agent ten zbiera informacje o systemie operacyjnym, zainstalowanych pakietach oraz dostępnych aktualizacjach bezpośrednio z instancji VM.
- Patch Status Dashboard: VM Manager udostępnia w konsoli Google Cloud gotowy pulpit nawigacyjny (dashboard), który w czasie rzeczywistym (lub z niewielkim opóźnieniem) pokazuje stan "zdrowia" floty maszyn pod kątem poprawek. Pozwala to na błyskawiczne wyeksportowanie listy maszyn z brakującymi poprawkami krytycznymi.
- Compliance & Speed: To rozwiązanie jest zaprojektowane dokładnie pod wymogi audytowe i compliance. Pozwala na wykonanie zadania "szybko" (quickly) i bez konieczności pisania własnych skryptów czy analizowania surowych logów.

Analiza niepoprawnych odpowiedzi:
- A. Security Command Center (SCC) scan: Choć SCC posiada moduł "Security Health Analytics", który wykrywa podatności, raportowanie konkretnie o brakujących poprawkach systemowych (patches) jest domeną VM Manager. SCC jest bardziej ogólnym narzędziem do wykrywania błędów konfiguracji chmurowej.
- B. gcloud CLI command for OS version: Sama wersja systemu operacyjnego (np. "Ubuntu 20.04.5") nie mówi audytorowi, czy wszystkie poprawki bezpieczeństwa zostały zainstalowane. Wymagałoby to ręcznego porównywania wersji z bazą patchy, co jest pracochłonne i wolne.
- C. Cloud Logging agent + last update log: Logi o ostatniej aktualizacji mogą być niekompletne lub trudne do wyciągnięcia (wymagają parsowania tekstu). Logging agent nie "wie", jakie poprawki są DOSTĘPNE u dostawcy systemu, a jedynie co zostało zrobione w przeszłości.

Wskazówki i triki (Tips & Tricks):
- "Compliance reporting" + "Missing OS patches" = OS Config / VM Manager.
- "Dashboard" w odpowiedziach dotyczących monitorowania floty często wskazuje na najbardziej efektywne (najszybsze) rozwiązanie.
- Pamiętaj: OS Config agent jest domyślnie zainstalowany na wielu obrazach Google Cloud (np. Compute Engine, Container-Optimized OS), ale musi zostać włączony w metadanych.

Praktyczne informacje na egzamin:
- Zrozum różnicę: **OS Inventory** (co mam zainstalowane?), **OS Patch** (czego mi brakuje?), **OS Policy** (co muszę mieć skonfigurowane?). Wszystkie trzy to części VM Manager.
- Audytorzy uwielbiają dashboardy VM Manager, ponieważ dają one jasny dowód "zgodności" (Compliance) całej infrastruktury.

Analiza i Podsumowanie (AI)

Kluczowe zagadnienia

Sugerowana odpowiedź: D

Analiza strategiczna: To pytanie sprawdza umiejętność wyboru odpowiedniego narzędzia do specyficznego zadania administracyjnego. W chmurze często istnieje wiele sposobów na osiągnięcie celu (skrypty, logi, skany), ale Google promuje rozwiązania "Managed", które dają najwyższą wiarygodność danych audytowych przy minimalnym wysiłku ludzkim.

Dodatkowe wskazówki

  • VM Manager integruje się również z "Vulnerability Management" w SCC, co pozwala widzieć brakujące patche jako luki bezpieczeństwa (CVE).
  • Możesz filtrować dashboardy po projektach, regionach i tagach, co ułatwia przygotowanie raportów dla różnych jednostek biznesowych.
