Question 170 / 361

Audit changes to organization-level policies. Which log source?

  • A. Admin Activity logs
  • B. Data Access logs
  • C. System Event logs
  • D. VPC Flow Logs
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

Odpowiedź: A.

Wyjaśnienie (Dlaczego poprawna):
A. Admin Activity logs: Każda zmiana polityki organizacji (np. włączenie zakazu publicznych IP) jest operacją administracyjną modyfikującą metadane organizacji. Takie zdarzenia trafiają wyłącznie do dziennika Admin Activity.

Dlaczego inne są błędne:
B. Data Access: Rejestrują użycie usług, a nie zmianę ich globalnych reguł (policy).
C. System Event: Dotyczą problemów Google.
D. VPC Flow Logs: Dotyczą pakietów sieciowych.

Konsensus społeczności ExamTopics: 100% na A. Podstawowa wiedza o audycie Governance.

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: A

Analiza spornych kwestii (AI): Na forach podkreśla się, że te logi są kluczowe dla wykrywania 'Insider Threat' – sytuacji, w której nieuczciwy admin wyłącza zabezpieczenia (np. zakaz zewnętrznych IP), aby ułatwić sobie kradzież danych.
