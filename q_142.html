Question 142 / 361

You have noticed an increased number of phishing attacks across your enterprise user accounts. You want to implement the Google 2-Step Verification (2SV) option that uses a cryptographic signature to authenticate a user and verify the URL of the login page. Which Google 2SV option should you use?

  • A. Titan Security Keys
  • B. Google prompt
  • C. Google Authenticator app
  • D. Cloud HSM keys
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
A. Titan Security Keys

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Firma boryka się z atakami phishingowymi. Należy wdrożyć opcję dwuetapowej weryfikacji (2-Step Verification - 2SV), która wykorzystuje podpis kryptograficzny i weryfikuje adres URL strony logowania przed autoryzacją użytkownika:
- Klucze bezpieczeństwa Titan (Titan Security Keys) wspierają standardy FIDO/WebAuthn. Podczas logowania klucz fizycznie nawiązuje kryptograficzny uścisk dłoni z przeglądarką. System weryfikuje tożsamość klucza oraz powiązanie z konkretnym adresem URL strony logowania Google. Jeśli użytkownik znajdzie się na sfałszowanej stronie phishingowej (która wygląda identycznie jak strona logowania, ale ma inny adres URL), klucz bezpieczeństwa wykryje różnicę w nazwie domeny i odmówi wygenerowania podpisu kryptograficznego, chroniąc poświadczenia przed kradzieżą. Jest to najbardziej odporna na phishing metoda MFA dostępna na rynku.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- B. Google prompt (Powiadomienie Google): Wyświetla komunikat "Czy to Ty logujesz się?" na ekranie telefonu komórkowego. Jest to wygodna metoda, ale nie wykorzystuje weryfikacji adresu URL w sposób odporny na ataki socjotechniczne (użytkownik może kliknąć "Tak" na telefonie, logując się na fałszywej stronie).
- C. Aplikacja Google Authenticator (TOTP): Generuje jednorazowe kody czasowe. Metoda ta jest podatna na phishing, ponieważ użytkownik może przepisać wygenerowany kod na fałszywej stronie internetowej, a atakujący może go natychmiast przechwycić i wykorzystać.
- D. Klucze Cloud HSM: Cloud HSM to sprzętowy moduł bezpieczeństwa w chmurze używany do generowania i przechowywania kluczy kryptograficznych dla aplikacji chmurowych (szyfrowanie CMEK). Nie służy do uwierzytelniania logowania użytkowników końcowych do kont.

4. Wskazówki, hinty, tips and tricks:
- W terminologii bezpieczeństwa IT jedyną metodą MFA/2FA w pełni odporną na zaawansowany phishing (phishing-resistant MFA) są **fizyczne klucze bezpieczeństwa U2F/FIDO2** (Titan Security Keys).
- Powiązanie z domeną i podpis kryptograficzny uniemożliwiają przekazanie poświadczeń oszustowi.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Ochrona przed phishingiem + podpis kryptograficzny + weryfikacja URL -> Titan Security Keys.
