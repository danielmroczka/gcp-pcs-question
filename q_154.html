Question 154 / 361

Your company's cloud security policy dictates that VM instances should not have an external IP address. You need to identify the Google Cloud service that will allow VM instances without external IP addresses to connect to the internet to update the VMs. Which service should you use?

  • A. Identity Aware-Proxy
  • B. Cloud NAT
  • C. TCP/UDP Load Balancing
  • D. Cloud DNS
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
B. Cloud NAT

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Polityka bezpieczeństwa zabrania maszynom wirtualnym posiadania publicznych adresów IP. Maszyny muszą jednak pobierać aktualizacje oprogramowania z internetu (ruch wychodzący):
- Cloud NAT (Network Address Translation) to usługa, która rozwiązuje ten problem. Umożliwia ona instancjom maszyn wirtualnych z adresami wyłącznie prywatnymi bezpieczny dostęp do internetu w celu pobierania aktualizacji, pakietów i wywoływania zewnętrznych API.
- Ruch jest tłumaczony na bramie Cloud NAT, co zapobiega bezpośredniemu skanowaniu i atakom z internetu na maszyny VM, ponieważ brama nie przepuszcza ruchu przychodzącego inicjowanego z zewnątrz.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- A. Identity-Aware Proxy (IAP): Służy do bezpiecznego dostępu *przychodzącego* (inbound) dla administratorów (np. tunelowanie SSH/RDP) bez publicznego IP, ale nie umożliwia samej maszynie wirtualnej nawiązywania połączeń *wychodzących* do internetu.
- C. TCP/UDP Load Balancing: Służy do rozdzielania ruchu *przychodzącego* (inbound) od klientów do maszyn backendowych, nie obsługuje ruchu wychodzącego inicjowanego przez maszyny.
- D. Cloud DNS: Służy wyłącznie do translacji nazw domenowych na adresy IP, nie trasuje ruchu i nie zapewnia łączności sieciowej z internetem.

4. Wskazówki, hinty, tips and tricks:
- Jeśli maszyny wirtualne w GCP **nie mogą mieć zewnętrznych adresów IP**, a potrzebują dostępu do internetu (outbound internet access) np. po aktualizacje lub pakiety apt/yum, jedynym poprawnym rozwiązaniem systemowym jest **Cloud NAT**.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Brak zewnętrznych IP na VM + połączenie wychodzące do internetu po aktualizacje -> Cloud NAT.

6. Dodatkowe źródła i dokumentacja:
