Question 70 / 361

Which international compliance standard provides guidelines for information security controls applicable to cloud services?

  • A. ISO 27001
  • B. ISO 27002
  • C. ISO 27017
  • D. ISO 27018
Show Suggested Answer Hide Answer
Suggested Answer: C

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:

C. ISO 27017 (Which international compliance standard provides guidelines for information security controls applicable to cloud services?)

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):

Prawidłową odpowiedzią jest ISO/IEC 27017, ponieważ jest to międzynarodowy standard, który w sposób jednoznaczny i szczegółowy określa wytyczne dotyczące kontroli bezpieczeństwa informacji specyficznie dla usług chmurowych. Jest to rozszerzenie rodziny norm ISO/IEC 27000, stworzone z myślą o unikalnych wyzwaniach i modelach operacyjnych środowisk chmurowych.

ISO/IEC 27017 "Code of practice for information security controls based on ISO/IEC 27002 for cloud services" dostarcza wytycznych dla zarówno dostawców usług chmurowych (Cloud Service Providers – CSP), jak i klientów korzystających z chmury (Cloud Service Customers – CSC). Standard ten nie tylko adaptuje istniejące kontrole z ISO/IEC 27002 do kontekstu chmury, ale także wprowadza nowe, specyficzne dla chmury kontrole i wytyczne. Przykładowo, obejmuje on takie aspekty jak podział obowiązków (Shared Responsibility Model), zarządzanie aktywami w chmurze, wirtualizację, zabezpieczanie środowisk wirtualnych, zarządzanie dostępem do chmury, logowanie i monitorowanie w środowiskach chmurowych, czy też usuwanie danych wirtualnych maszyn.

W kontekście GCP, wdrożenie i certyfikacja zgodności z ISO/IEC 27017 oznacza, że Google Cloud stosuje rygorystyczne praktyki bezpieczeństwa, które są uznawane na całym świecie za najlepsze praktyki w zakresie ochrony informacji w chmurze. Dla inżyniera bezpieczeństwa, zrozumienie tego standardu jest kluczowe, ponieważ pomaga w projektowaniu architektur zgodnych z wymogami regulacyjnymi, ocenie ryzyka oraz implementacji kontroli bezpieczeństwa, które są spójne z międzynarodowymi wytycznymi. Wybór tej normy jest optymalny, ponieważ bezpośrednio adresuje "usługi chmurowe" i "kontrole bezpieczeństwa informacji", co idealnie pasuje do treści pytania. Jest to standard stworzony specjalnie, aby wypełnić lukę pomiędzy ogólnymi zasadami bezpieczeństwa a specyfiką działania w dynamicznym i rozproszonym środowisku chmurowym, oferując bardziej szczegółowe i adekwatne wytyczne niż ogólne normy.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:

1.  A. ISO 27001:
    ISO/IEC 27001 "Information security management systems – Requirements" to norma określająca wymagania dla Systemu Zarządzania Bezpieczeństwem Informacji (Information Security Management System – ISMS). Nie dostarcza ona szczegółowych wytycznych dotyczących kontroli bezpieczeństwa informacji jako takich, lecz jest to rama, która pomaga organizacjom w ustanowieniu, wdrożeniu, utrzymaniu i ciągłym doskonaleniu ISMS. Chociaż certyfikacja na zgodność z ISO 27001 jest podstawą dla bezpieczeństwa informacji, a jej załącznik A zawiera listę domen kontroli, to sama norma nie jest przeznaczona do szczegółowego opisu implementacji tych kontroli, a tym bardziej nie jest specyficzna dla usług chmurowych. Pytanie prosi o "guidelines for information security controls applicable to cloud services", co wykracza poza zakres samego ISMS.

2.  B. ISO 27002:
    ISO/IEC 27002 "Information technology – Security techniques – Code of practice for information security controls" to ogólny kodeks praktyk dla kontroli bezpieczeństwa informacji. Norma ta zawiera szczegółowe wytyczne dotyczące najlepszych praktyk w zakresie zarządzania bezpieczeństwem informacji, opisując szereg kontroli, które organizacje mogą wdrożyć. Jest to standard, na którym bazują rozszerzenia takie jak ISO 27017. Jednakże, ISO 27002 jest standardem ogólnym i nie uwzględnia specyfiki ani unikalnych zagrożeń i możliwości związanych z usługami chmurowymi. Brakuje jej konkretnych zaleceń dotyczących podziału obowiązków, zarządzania środowiskami wirtualnymi czy specyficznych umów SLA w chmurze. Stąd, mimo że jest to norma dotycząca kontroli bezpieczeństwa, nie jest "applicable to cloud services" w tak precyzyjny sposób, jak wymaga tego pytanie.

3.  D. ISO 27018:
    ISO/IEC 27018 "Information technology – Security techniques – Code of practice for protection of personally identifiable information (PII) in public clouds acting as PII processors" jest standardem skierowanym na ochronę Danych Osobowych (Personally Identifiable Information – PII) w chmurach publicznych. Jego głównym celem jest zapewnienie prywatności i ochrony PII przetwarzanych przez dostawców usług chmurowych. Chociaż jest to standard specyficzny dla chmury i dotyczy bezpieczeństwa, jego zakres jest znacznie węższy niż wymagany przez pytanie. Pytanie dotyczy "information security controls" w ogólności, a nie wyłącznie ochrony PII. ISO 27018 nie obejmuje szerokiego spektrum kontroli bezpieczeństwa, takich jak zarządzanie tożsamością i dostępem (IAM) dla zasobów nieosobowych, bezpieczeństwo sieci, zarządzanie ciągłością działania czy fizyczne bezpieczeństwo centrów danych, które są kluczowe dla ogólnego bezpieczeństwa usług chmurowych i są adresowane przez ISO 27017.

4. Wskazówki, hinty, tips and tricks:

  Na egzaminie Google Cloud Certified Professional Cloud Security Engineer, pytania dotyczące standardów zgodności (compliance standards) są powszechne i wymagają precyzyjnej znajomości zakresu poszczególnych norm. Oto kilka wskazówek:

  1.  Słowa kluczowe w pytaniu są decydujące: Zawsze szukaj w pytaniu precyzyjnych terminów. Jeśli pytanie wspomina o "cloud services" i "information security controls", automatycznie powinieneś myśleć o standardach rozszerzających ogólne ISO 2700x, które są specyficzne dla chmury.
  2.  Zrozumienie hierarchii ISO 27000:
      *   ISO 27001: ISMS, system zarządzania.
      *   ISO 27002: Ogólne kontrole, kodeks praktyk.
      *   ISO 27017: Kontrole dla usług chmurowych.
      *   ISO 27018: Ochrona PII w chmurze.
  3.  Zapamiętaj końcówki numeracji dla chmury:
      *   17 to ogólne bezpieczeństwo w chmurze ("cloud security controls"). Myśl o "17" jako o "całościowym spojrzeniu na chmurę".
      *   18 to ochrona danych osobowych (PII) w chmurze ("cloud PII protection"). Myśl o "18" jako o "prywatności w chmurze".
  4.  Unikaj uogólnień: Jeśli odpowiedź jest zbyt ogólna (np. tylko ISO 27001 lub 27002), a pytanie precyzuje "cloud services", prawdopodobnie nie jest to najlepsza opcja. Zawsze szukaj najbardziej specyficznej i adekwatnej normy.
  5.  Pułapki językowe: Zwróć uwagę na subtelne różnice między "security controls" a "PII protection". Te terminy nie są wymienne i wskazują na różne standardy. Pytania mogą próbować zmylić, używając ogólnego "security" zamiast "privacy", gdy kontekst dotyczy PII.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):

  Na podstawie analizy pytań egzaminacyjnych i struktury standardów ISO 27000, można sformułować następujące reguły wyboru odpowiedzi:

  1.  Jeśli pytanie wspomina o "guidelines for information security controls" LUB "code of practice for cloud services" LUB "security practices for cloud providers and customers", to szukaj odpowiedzi zawierającej ISO 27017. Słowa kluczowe: "cloud services", "information security controls", "guidelines".
  2.  Jeśli pytanie wspomina o "protection of personally identifiable information (PII)" LUB "privacy in public clouds" LUB "handling of personal data in cloud environments", to szukaj odpowiedzi zawierającej ISO 27018. Słowa kluczowe: "PII", "personal data", "privacy", "public clouds".
  3.  Jeśli pytanie wspomina o "Information Security Management System (ISMS)" LUB "requirements for establishing an ISMS", to szukaj odpowiedzi zawierającej ISO 27001. Słowa kluczowe: "ISMS", "requirements", "management system".
  4.  Jeśli pytanie wspomina o "general code of practice for information security controls" LUB "general guidelines for security controls" bez specyficznego odniesienia do chmury lub PII, to szukaj odpowiedzi zawierającej ISO 27002. Słowa kluczowe: "code of practice", "general controls".
  5.  Gdy pytanie zawiera zarówno "cloud services" jak i "security controls", priorytetem jest zawsze najbardziej specyficzny standard, czyli w tym przypadku ISO 27017, a nie jego ogólne podstawy (27001, 27002).
