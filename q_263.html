Question 263 / 361

Your organization relies heavily on virtual machines (VMs) in Compute Engine. Due to team growth and resource demands, VM sprawl is becoming problematic. Maintaining consistent security hardening and timely package updates poses an increasing challenge. You need to centralize VM image management and automate the enforcement of security baselines throughout the virtual machine lifecycle. What should you do?

  • A. Use VM Manager to automatically distribute and apply patches to VMs across your projects. Integrate VM Manager with hardened, organization-standard VM images stored in a central repository.
  • B. Configure the sole-tenancy feature in Compute Engine for all projects. Set up custom organization policies in Policy Controller to restrict the operating systems and image sources that teams are allowed to use.
  • C. Create a Cloud Build trigger to build a pipeline that generates hardened VM images. Run vulnerability scans in the pipeline, and store images with passing scans in a registry. Use instance templates pointing to this registry.
  • D. Activate Security Command Center Enterprise. Use VM discovery and posture management features to monitor hardening state and trigger automatic responses upon detection of issues.
Show Suggested Answer
Suggested Answer: A

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
A. Use VM Manager to automatically distribute and apply patches to VMs across your projects. Integrate VM Manager with hardened, organization-standard VM images stored in a central repository.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Odpowiedź A jest prawidłowa, ponieważ łączy centralne zarządzanie utwardzonymi obrazami maszyn wirtualnych z automatyzacją procesu instalowania poprawek (patching) w skali całej organizacji.

Zalety tego rozwiązania:
a. **Centralny rejestr obrazów (Central Repository):** Stworzenie zaufanego projektu, w którym przechowywane są certyfikowane, utwardzone obrazy maszyn (hardened images) pozwala na wymuszenie stosowania wyłącznie tych obrazów przez inne zespoły (np. za pomocą polityki organizacji `constraints/compute.trustedImageProjects`).
b. **Automatyzacja poprawek (VM Manager):** Usługa OS Patch Management w VM Managerze pozwala na definiowanie harmonogramów aktualizacji systemów operacyjnych dla wszystkich maszyn wirtualnych w wielu projektach jednocześnie. Gwarantuje to, że nowo uruchomione maszyny oraz te już działające są stale patchowane i zgodne z baselinem bezpieczeństwa.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
B. Configure the sole-tenancy feature in Compute Engine for all projects...
   * Dlaczego nieprawidłowa: Sole-tenancy (wyłączna dzierżawa) gwarantuje, że maszyny wirtualne działają na dedykowanym fizycznym sprzęcie. Służy to do celów licencyjnych i izolacji fizycznej, ale nie rozwiązuje problemów z aktualizacją oprogramowania (patching) i zapobieganiem VM sprawl.
C. Create a Cloud Build trigger to build a pipeline... Use instance templates pointing to this registry.
   * Dlaczego nieprawidłowa: Choć budowanie obrazów w Cloud Build jest poprawną praktyką, to samo utworzenie szablonów instancji (instance templates) nie rozwiązuje problemu ciągłego zarządzania aktualizacjami (patching) na już działających maszynach wirtualnych w ich cyklu życia, co wymaga systemu takiego jak VM Manager.
D. Activate Security Command Center Enterprise. Use VM discovery and posture management...
   * Dlaczego nieprawidłowa: SCC Enterprise pozwala na monitorowanie stanu maszyn i zgłaszanie alertów o braku poprawek (compliance), ale nie jest dedykowanym narzędziem do bezpośredniego wdrażania aktualizacji pakietów systemowych na maszynach w taki sposób jak VM Manager.

4. Wskazówki, hinty, tips and tricks:
* VM Sprawl i spójność poprawek systemowych -> Zawsze używaj **VM Manager** (OS Patch Management).
* Do wymuszenia bezpiecznych obrazów bazowych stosuj **Trusted Image Projects** na poziomie polityki organizacji.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
* Centralize VM image management + automate patch enforcement -> VM Manager + central repository of hardened images.
