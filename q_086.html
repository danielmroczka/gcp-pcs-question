Question 86 / 361

You are part of a security team investigating a compromised service account key. You need to audit which new resources were created by the service account.
What should you do?

  • A. Query Data Access logs.
  • B. Query Admin Activity logs.
  • C. Query Access Transparency logs.
  • D. Query Stackdriver Monitoring Workspace.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Potwierdzona odpowiedź: B (Query Admin Activity logs)

Wyjaśnienie: 
Admin Activity logs rejestrują operacje zapisu, które modyfikują konfigurację lub stan zasobów (np. tworzenie instancji, tworzenie bucketów). Są one domyślnie włączone i bezpłatne, co czyni je pierwszym miejscem do sprawdzenia, jakie zasoby zostały stworzone przez dany podmiot (np. skompromitowane konto).

Dlaczego pozostałe są błędne:
A. Data Access logs rejestrują odczyty i zapisy samych DANYCH (np. odczyt obiektu w GCS), a nie tworzenie zasobów infrastruktury.
C. Access Transparency logs służą do śledzenia dostępu pracowników Google do Twoich danych.
D. Stackdriver Monitoring (Cloud Monitoring) służy do metryk wydajnościowych, a nie audytu operacji administracyjnych.

Wskazówki egzaminacyjne (Tips & Tricks):
Tworzenie zasobów = Admin Activity. Dostęp do danych = Data Access.

Kluczowe zagadnienia do powtórzenia:
- Cloud Audit Logs types
- Admin Activity vs Data Access logs
- Security Investigation in GCP
