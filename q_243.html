Question 243 / 361

An administrative application is running on a virtual machine (VM) in a managed group at port 5601 inside a Virtual Private Cloud (VPC) instance without access to the internet currently. You want to expose the web interface at port 5601 to users and enforce authentication and authorization Google credentials. What should you do?

  • A. Configure the bastion host with OS Login enabled and allow connection to port 5601 at VPC firewall. Log in to the bastion host from the Google Cloud console by using SSH-in-browser and then to the web application.
  • B. Modify the VPC routing with the default route point to the default internet gateway. Modify the VPC Firewall rule to allow access from the internet 0.0.0.0/0 to port 5601 on the application instance.
  • C. Configure Secure Shell Access (SSH) bastion host in a public network, and allow only the bastion host to connect to the application on port 5601. Use a bastion host as a jump host to connect to the application.
  • D. Configure an HTTP Load Balancing instance that points to the managed group with Identity-Aware Proxy (IAP) protection with Google credentials. Modify the VPC firewall to allow access from IAP network range.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wskazówki egzaminacyjne (Tips & Tricks)

Reguła Egzaminacyjna (Exam Rule): 
Jeśli scenariusz dotyczy zabezpieczania zasobów chmurowych (GCP), zawsze wybieraj rozwiązanie typu Managed (SCC, Secret Manager, Cloud KMS), a unikaj rozwiązań self-managed, chyba że pytanie wyraźnie wymaga dostosowania niskopoziomowego.

Haczyki egzaminacyjne (Exam Traps):
- Pułapka IAM: Pytania o uprawnienia często sugerują 'Project Owner' – zawsze szukaj 'Least Privilege' (np. 'Role: Secret Manager Secret Accessor').
- Pułapka Sieciowa: Często mylone są VPC Peering (wydajność) oraz VPN (szyfrowanie/on-premise).

Głębokie wyjaśnienie techniczne:
Rozwiązanie bazuje na GCP Shared Responsibility Model. Google zarządza bezpieczeństwem infrastruktury (Physical, Network, Host), podczas gdy administrator zarządza tożsamością (IAM), danymi (Encryption, Cloud KMS) i regułami dostępu (VPC Firewall).

Wyjaśnienie

Potwierdzona odpowiedź: D (Configure an HTTP Load Balancing instance that points to the managed group with Identity-Aware Proxy (IAP) protection with Google credentials. Modify the VPC firewall to allow access from IAP network range.)

Wyjaśnienie:
- Identity-Aware Proxy (IAP): Pozwala na bezpieczne wystawienie aplikacji webowych (HTTPS) w internecie bez konieczności używania VPN. Użytkownicy logują się przy użyciu poświadczeń Google, co automatycznie zapewnia autoryzację i uwierzytelnienie.
- Load Balancer: IAP dla aplikacji webowych (HTTP/S) działa w oparciu o zewnętrzny Load Balancer (GCLB).
- Bezpieczeństwo: IAP pozwala na uniknięcie otwierania portu 5601 dla całego świata. Ruch przechodzi przez infrastrukturę Google, gdzie IAP weryfikuje tożsamość użytkownika przed przekazaniem zapytania do aplikacji.
- IAP IP Range: Aby IAP mógł komunikować się z Twoimi instancjami, musisz pozwolić na ruch z zakresu IP: `35.235.240.0/20` w regułach firewalla VPC.

Dlaczego pozostałe odpowiedzi są niepoprawne:
- A. Bastion host: To przestarzałe podejście. Wymaga od użytkowników ręcznego logowania się na serwer pośredniczący, co jest niebezpieczne, trudne w audytowaniu i niewygodne.
- B. Internet gateway: Wystawienie aplikacji bezpośrednio na port 5601 do internetu (0.0.0.0/0) bez żadnej warstwy uwierzytelnienia to krytyczna luka bezpieczeństwa.
- C. Bastion host (Jump host): Podobnie jak w opcji A, bastion host to dodatkowa maszyna, którą trzeba utrzymywać i patchować. IAP jest usługą zarządzaną, więc eliminuje ten narzut.

Wskazówki i triki (Tips & Tricks):
- "Expose web interface" + "Google credentials" = IAP (HTTP/S) + Load Balancer.
- Zakres IP dla IAP TCP forwarding: `35.235.240.0/20`.

Praktyczne informacje na egzamin:
- Zapamiętaj: IAP działa na warstwie 7 (HTTP/S) w połączeniu z Load Balancerem.
- IAP jest fundamentem modelu Zero Trust (BeyondCorp) w Google Cloud.

Analiza i Podsumowanie (AI)

Kluczowe zagadnienia

Sugerowana odpowiedź: D

Analiza strategiczna: To pytanie testuje Twoją znajomość nowoczesnych metod wystawiania usług wewnątrz VPC. Zamiast starych metod (bastion hosty), GCP promuje IAP – usługę, która przenosi punkt autoryzacji z poziomu firewalli sieciowych na poziom tożsamości użytkownika. To kluczowa koncepcja egzaminacyjna.
