Question 107 / 361

Your organization recently deployed a new application on Google Kubernetes Engine. You need to deploy a solution to protect the application. The solution has the following requirements:
* Scans must run at least once per week
* Must be able to detect cross-site scripting vulnerabilities
* Must be able to authenticate using Google accounts
Which solution should you use?

  • A. Google Cloud Armor
  • B. Web Security Scanner
  • C. Security Health Analytics
  • D. Container Threat Detection
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Potwierdzona odpowiedź: B (Web Security Scanner)

Wyjaśnienie:
- Web Security Scanner (WSS): Jest to dedykowane narzędzie do wykrywania podatności w aplikacjach internetowych (DAST). Automatycznie skanuje aplikacje pod kątem typowych zagrożeń, takich jak Cross-Site Scripting (XSS).
- Harmonogram skanowania: WSS pozwala na definiowanie harmonogramów (np. raz w tygodniu), co spełnia wymóg regularnych skanów.
- Uwierzytelnianie kontami Google: Jest to jedna z kluczowych funkcji WSS, która pozwala na skanowanie części aplikacji dostępnych tylko po zalogowaniu, przy użyciu tożsamości Google.
- Wsparcie dla GKE: WSS może skanować aplikacje hostowane na GKE, Compute Engine oraz App Engine.

Dlaczego pozostałe są błędne:
- A: Google Cloud Armor to firewall aplikacji webowych (WAF), który chroni przed atakami w czasie rzeczywistym, ale nie przeprowadza proaktywnych skanów kodu pod kątem podatności.
- C: Security Health Analytics (SHA) skupia się na bezpieczeństwie samej platformy (konfiguracji zasobów GCP, np. otwartych reguł zapory), a nie na lukach w logice i kodzie aplikacji webowej.
- D: Container Threat Detection monitoruje podejrzaną aktywność wewnątrz uruchomionych kontenerów (runtime security), np. próby instalacji rootkitów, a nie skanuje interfejsu webowego aplikacji.

Wskazówki egzaminacyjne (Tips & Tricks):
- Słowo klucz "Scan" + "XSS" + "Application" = Web Security Scanner.
- Pamiętaj, że WSS wykrywa podatności "od zewnątrz" (podobnie jak haker), udając ruch przeglądarkowy.

Kluczowe zagadnienia do powtórzenia:
- Możliwości Web Security Scanner (WSS).
- Różnica między WAF (Cloud Armor) a DAST (WSS).
- Skanery wbudowane w Security Command Center.
