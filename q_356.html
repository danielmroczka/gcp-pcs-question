Question 356 / 361

Your organization is using Google Workspace, Google Cloud, and a third-party SIEM. You need to export events such as user logins, successful logins, and failed logins to the SIEM. Logs need to be ingested in real time or near real-time. What should you do?

  • A. Poll Cloud Logging for authentication events using the gcloud logging read tool. Forward the events to the SIEM.
  • B. Configure Google Workspace to directly send logs to the API endpoint of the third-party SIEM.
  • C. Create a Cloud Storage bucket as a sink for all logs. Configure the SIEM to periodically scan the bucket for new log files.
  • D. Create a Cloud Logging sink to export relevant authentication logs to a Pub/Sub topic for SIEM subscription.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

Poprawna odpowiedź: D (Create a Cloud Logging sink to export relevant authentication logs to a Pub/Sub topic for SIEM subscription.)

Dlaczego ta odpowiedź jest poprawna:
- Log Sinks + Pub/Sub: To natywne, skalowalne i "near real-time" rozwiązanie do przesyłania logów z Google Cloud do dowolnego SIEM. Pub/Sub służy jako bufor, który SIEM może subskrybować.
- Logi Google Workspace: Logi Workspace mogą być przesyłane do Cloud Logging, co pozwala na ich późniejszą eksportację tym samym mechanizmem (Log Sink).

Analiza niepoprawnych odpowiedzi:
- A. Poll gcloud: Nieefektywne, wymaga pisania własnego kodu ("management overhead") i nie zapewnia dobrej wydajności.
- B. Send to API endpoint: Google Workspace nie ma natywnej funkcji wysyłania logów bezpośrednio do endpointów API stron trzecich.
- C. Bucket scan: To metoda "batch" (okresowe skanowanie), nie "real-time" lub "near real-time".

Wskazówki i triki (Tips & Tricks):
- "Logs" + "SIEM" + "Real-time" = Pub/Sub (Sink).

Praktyczne informacje na egzamin:
- Zapamiętaj: W GCP logi do SIEM zawsze wysyłamy przez Pub/Sub (Log Sink -> Pub/Sub -> SIEM).

Kluczowe zagadnienia

Sugerowana odpowiedź: D

Analiza strategiczna: Pytanie o architekturę logowania w skali. Wykorzystanie Pub/Sub jako pośrednika ("message bus") między GCP (Cloud Logging) a systemami SIEM jest standardem w projektach korporacyjnych.
