Question 123 / 361

You need to connect your organization's on-premises network with an existing Google Cloud environment that includes one Shared VPC with two subnets named Production and Non-Production. You are required to: Use a private transport link. Configure access to Google Cloud APIs through private API endpoints originating from on-premises environments. Ensure that Google Cloud APIs are only consumed via VPC Service Controls. What should you do?

  • A. 1. Set up a Cloud VPN link between the on-premises environment and Google Cloud. 2. Configure private access using the restricted.googleapis.com domains in on-premises DNS configurations.
  • B. 1. Set up a Partner Interconnect link between the on-premises environment and Google Cloud. 2. Configure private access using the private.googleapis.com domains in on-premises DNS configurations.
  • C. 1. Set up a Direct Peering link between the on-premises environment and Google Cloud. 2. Configure private access for both VPC subnets.
  • D. 1. Set up a Dedicated Interconnect link between the on-premises environment and Google Cloud. 2. Configure private access using the restricted.googleapis.com domains in on-premises DNS configurations.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

Potwierdzona odpowiedź: D (1. Set up a Dedicated Interconnect link between the on-premises environment and Google Cloud. 2. Configure private access using the restricted.googleapis.com domains in on-premises DNS configurations.)

Wyjaśnienie:
Dedicated Interconnect to fizyczne, prywatne połączenie o wysokiej przepustowości między siecią on-premises a Google Cloud, spełniające wymóg "private transport link". Aby zapewnić, że usługi API Google są konsumowane wyłącznie przez VPC Service Controls, należy użyć domeny restricted.googleapis.com (IP 199.36.153.4/30). Ta domena ogranicza dostęp tylko do usług wspieranych przez VPC SC, co zapobiega eksfiltracji danych do innych usług Google poza perymetrem.

Dlaczego pozostałe odpowiedzi są niepoprawne:
- A: Cloud VPN działa przez publiczny internet, co nie spełnia wymogu dedykowanego "private transport link" w kontekście wysokiej wydajności i izolacji fizycznej.
- B: Domena private.googleapis.com (IP 199.36.153.8/30) pozwala na dostęp do większości usług Google (w tym Gmail czy YouTube), co nie spełnia wymogu ograniczenia dostępu tylko do usług objętych perymetrem VPC Service Controls.
- C: Direct Peering to publiczny peering z Google, który nie zapewnia prywatnej łączności z siecią VPC (Shared VPC).

Wskazówki i triki (Tips & Tricks):
- "Private transport link" = Dedicated Interconnect.
- "VPC Service Controls only" = restricted.googleapis.com.
- "All Google APIs" = private.googleapis.com.

Praktyczne informacje na egzamin:
- Pamiętaj o konieczności skonfigurowania tras BGP dla adresów IP restricted/private VIP w sieci on-premises.
- VPC Service Controls jest kluczowy dla zgodności z regulacjami dotyczącymi ochrony danych (np. HIPAA, PCI DSS).

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: D

Głęboka analiza: Połączenie Dedicated Interconnect z restricted.googleapis.com tworzy najbezpieczniejszą możliwą ścieżkę dla danych wrażliwych. Rozwiązanie to eliminuje ryzyko ataku Man-in-the-Middle z internetu publicznego oraz drastycznie ogranicza "powierzchnię ataku" API Google tylko do tych usług, które Twoja firma faktycznie autoryzowała wewnątrz perymetru bezpieczeństwa.
