Question 123 / 361

You need to connect your organization's on-premises network with an existing Google Cloud environment that includes one Shared VPC with two subnets named Production and Non-Production. You are required to: Use a private transport link. Configure access to Google Cloud APIs through private API endpoints originating from on-premises environments. Ensure that Google Cloud APIs are only consumed via VPC Service Controls. What should you do?

  • A. 1. Set up a Cloud VPN link between the on-premises environment and Google Cloud. 2. Configure private access using the restricted.googleapis.com domains in on-premises DNS configurations.
  • B. 1. Set up a Partner Interconnect link between the on-premises environment and Google Cloud. 2. Configure private access using the private.googleapis.com domains in on-premises DNS configurations.
  • C. 1. Set up a Direct Peering link between the on-premises environment and Google Cloud. 2. Configure private access for both VPC subnets.
  • D. 1. Set up a Dedicated Interconnect link between the on-premises environment and Google Cloud. 2. Configure private access using the restricted.googleapis.com domains in on-premises DNS configurations.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
D. 1. Set up a Dedicated Interconnect link between the on-premises environment and Google Cloud. 2. Configure private access using the restricted.googleapis.com domains in on-premises DNS configurations.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Wymagania to: połączenie hybrydowe za pomocą prywatnego łącza transportowego (private transport link), prywatny dostęp do API Google z lokalizacji on-premises oraz ograniczenie dostępu do API wyłącznie do tych, które są objęte ochroną VPC Service Controls:
- Dedicated Interconnect zapewnia fizyczne, prywatne połączenie światłowodowe o najwyższym poziomie bezpieczeństwa i przepustowości (spełnia warunek "private transport link").
- Skierowanie ruchu do Google APIs na domenę `restricted.googleapis.com` (rozwiązującą się na zakres IP 199.36.153.4/30) powoduje, że zapytania są kierowane wyłącznie do usług Google obsługiwanych przez VPC Service Controls (np. Cloud Storage, BigQuery). Dostęp do innych, nieobsługiwanych usług (np. Gmail, YouTube) jest automatycznie blokowany, co zapobiega wyciekowi danych.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- A. Cloud VPN: Używa publicznego internetu jako nośnika dla zaszyfrowanych tuneli IPSec, co nie jest dedykowanym fizycznym łączem prywatnym o gwarantowanej jakości (Dedicated Interconnect jest rozwiązaniem wyższej klasy).
- B. Partner Interconnect z domeną `private.googleapis.com`: Domena `private.googleapis.com` (199.36.153.8/30) umożliwia dostęp do wszystkich usług Google (w tym konsumenckich i nieobjętych VPC Service Controls), co narusza wymóg ograniczania dostępu wyłącznie do usług chronionych przez VPC SC.
- C. Direct Peering: Jest to połączenie typu peering realizowane na publicznych adresach IP bez integracji z prywatnymi sieciami VPC, przez co nie wspiera bezproblemowego routingu hybrydowego do Shared VPC i nie jest w pełni prywatnym łączem transportowym.

4. Wskazówki, hinty, tips and tricks:
- Zapamiętaj kluczową różnicę dla egzaminu:
  - `restricted.googleapis.com` -> Dostęp TYLKO do API wspieranych przez VPC Service Controls (wymagane w scenariuszach z VPC SC).
  - `private.googleapis.com` -> Dostęp do WSZYSTKICH API Google Cloud i Google Workspace.
- Prywatne łącze o najwyższym standardzie bezpieczeństwa dla przedsiębiorstw to Dedicated Interconnect.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Wymóg VPC Service Controls dla połączenia hybrydowego -> restricted.googleapis.com.
- Prywatne dedykowane łącze fizyczne -> Dedicated Interconnect.

6. Dodatkowe źródła i dokumentacja:
- Configure private connectivity for Google APIs: https://cloud.google.com/vpc-service-controls/docs/private-connectivity
