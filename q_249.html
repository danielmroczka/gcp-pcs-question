Question 249 / 361

Analyze VPC network traffic to detect data exfiltration via DNS exfiltration (unusual query volumes). Which service?

  • A. Cloud Armor
  • B. Cloud IDS
  • C. Event Threat Detection (ETD) with Cloud Logging
  • D. IAP
Show Suggested Answer Hide Answer
Suggested Answer: C

Wyjaśnienie

Odpowiedź: C.

Wyjaśnienie (Dlaczego poprawna):
C. ETD + Logging: Podobnie jak w pytaniu 223, ETD analizuje logi (Cloud DNS i VPC Flow Logs) i szuka anomalii ilościowych. Nagły skok liczby zapytań DNS o unikalne subdomeny jest klasyczną sygnaturą wycieku danych przez protokół DNS, co ETD wykrywa automatycznie.

Dlaczego inne są błędne:
A. Cloud Armor: Nie widzi ruchu DNS Twoich maszyn VM.
B. Cloud IDS: Wykrywa tunelowanie (treść), ale ETD (C) jest częściej optymalną odpowiedzią na 'unusual volumes' (statystyczne anomalie w logach).
D. IAP: Nie dotyczy ruchu sieciowego DNS.

Konsensus społeczności ExamTopics: 100% na C. Detekcja exfiltration na podstawie logów = ETD.

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: C

Analiza spornych kwestii (AI): Na GitHubie eksperci zauważają, że hakerzy często używają wolnych, ale stałych strumieni zapytań DNS, by nie wywołać alarmu. ETD (C) wykorzystuje modele ML Google, by odróżnić normalny ruch DNS od 'złośliwego szeptu' eksfiltracji.
