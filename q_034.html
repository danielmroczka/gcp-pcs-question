Question 34 / 361

Your company is using Cloud Dataproc. You want to be able to create, rotate, and destroy symmetric encryption keys used for persistent disks. What should you do?

  • A. Use Cloud KMS to manage DEK.
  • B. Use Cloud KMS to manage KEK.
  • C. Use CSEK to manage DEK.
  • D. Use CSEK to manage KEK.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Poprawna odpowiedź: B (Use Cloud KMS to manage KEK.)

Analiza poprawności:
Szyfrowanie kopertowe (Envelope Encryption) to fundament bezpiecznego zarządzania danymi w chmurze. W tym modelu istnieją dwa typy kluczy:
1. Klucz Danych (DEK - Data Encryption Key): Służy do szyfrowania właściwych danych (np. bloków dysku). Jest on generowany lokalnie dla wydajności i szybkości operacji.
2. Klucz Szyfrujący Klucz (KEK - Key Encryption Key): Służy do zaszyfrowania (opakowania) klucza DEK. To właśnie tym kluczem (KEK) zarządzasz w usłudze Cloud KMS. KMS pozwala na jego rotację, wyłączenie czy zniszczenie – a więc kontrolujesz cykl życia klucza nadrzędnego, który chroni wszystkie Twoje klucze danych.

Dlaczego pozostałe są błędne:
A, C (DEK): Użytkownik nigdy nie zarządza kluczami danych (DEK) bezpośrednio w Cloud KMS. DEK-i są efemeryczne, generowane "w locie" blisko danych i nie wymagają ręcznego zarządzania (rotacji/niszczenia).
D (CSEK): To usługa "Customer-Supplied Encryption Keys", gdzie dostarczasz własny klucz do każdej operacji. Nie używasz do tego Cloud KMS jako centralnego magazynu zarządzania.

Wskazówki egzaminacyjne:
- "Manage" + "Symmetric keys": Zawsze szukaj "Cloud KMS" i "KEK".
- Hierarchia: Użytkownik zarządza KEK (w KMS), system zarządza DEK (automatycznie).
- Eliminacja: Jeśli widzisz "manage DEK" – to zawsze błędna odpowiedź.

Dokumentacja:

Analiza i Wyjaśnienie

Sugerowana odpowiedź: B

Analiza spornych kwestii (AI): Kluczem do zrozumienia tego modelu jest fakt, że kontrola nad kluczem nadrzędnym (KEK) daje Ci "wyłącznik bezpieczeństwa" dla wszystkich danych zaszyfrowanych kluczami DEK z tego "kopertowego" łańcucha. Jeśli zniszczysz KEK, wszystkie dane chronione tym łańcuchem stają się trwale nieczytelne.
