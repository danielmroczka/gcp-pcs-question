Question 217 / 361

You are routing all your internet facing traffic from Google Cloud through your on-premises internet connection. You want to accomplish this goal securely and with the highest bandwidth possible. What should you do?

  • A. Create an HA VPN connection to Google Cloud. Replace the default 0.0.0.0/0 route.
  • B. Create a routing VM in Compute Engine. Configure the default route with the VM as the next hop.
  • C. Configure Cloud Interconnect with HA VPN. Replace the default 0.0.0.0/0 route to an on-premises destination.
  • D. Configure Cloud Interconnect and route traffic through an on-premises firewall.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

Potwierdzona odpowiedź: D (Configure Cloud Interconnect and route traffic through an on-premises firewall)

Dlaczego ta odpowiedź jest poprawnie:
- Cloud Interconnect: Jest to rozwiązanie dedykowane dla scenariuszy wymagających "najwyższej przepustowości" (highest bandwidth), znacznie przewyższającej możliwości tuneli VPN (które są ograniczane przez przepustowość internetu i limity tunelu).
- Forced Tunneling: Kierowanie całego ruchu internetowego (0.0.0.0/0) przez on-premises wymaga bezpiecznego i wydajnego kanału (Interconnect) oraz centralnego punktu inspekcji (Firewall on-premises), gdzie ruch może zostać przefiltrowany przez korporacyjne systemy bezpieczeństwa.
- Bezpieczeństwo: Przekierowanie ruchu przez on-premises firewall pozwala na stosowanie korporacyjnych standardów bezpieczeństwa (np. DLP, IDS/IPS, WAF) dla całego ruchu wychodzącego z chmury.

Dlaczego pozostałe odpowiedzi są niepoprawne:
- A. HA VPN: VPN jest świetnym rozwiązaniem dla średnich wymagań, ale nie zapewnia najwyższej dostępnej przepustowości (Interconnect jest szybszy i bardziej przewidywalny).
- B. Routing VM: Używanie maszyny wirtualnej (NAT/Gateway VM) jako routera dla całego ruchu w organizacji jest wąskim gardłem, trudne w skalowaniu i nieefektywne kosztowo. W GCP należy używać natywnych usług sieciowych (Cloud NAT/Interconnect).
- C. Cloud Interconnect with HA VPN: Choć można łączyć te technologie, samo "replacing the default route to an on-premises destination" nie opisuje pełnego procesu kontroli ruchu. Opcja D jest bardziej kompletna, wspominając o Firewallu jako punkcie decyzyjnym.

Wskazówki i triki (Tips & Tricks):
- "Highest bandwidth" + "Secure" = Cloud Interconnect.
- "Forced tunneling" / "Internet traffic through on-prem" = Interconnect + Central Firewall.
- Pamiętaj: Jeśli routing internetowy jest przekierowany, musisz zadbać o poprawną konfigurację tras (routes) oraz Cloud Routera.

Praktyczne informacje na egzamin:
- Zrozum: **Interconnect** (fizyczne połączenie) vs **VPN** (tunel przez internet).
- Cloud Interconnect zapewnia SLA (Service Level Agreement) dotyczące dostępności, co jest krytyczne dla usług biznesowych.

Wskazówki egzaminacyjne (Tips & Tricks)

Reguła Egzaminacyjna (Exam Rule): 
Jeśli scenariusz dotyczy zabezpieczania zasobów chmurowych (GCP), zawsze wybieraj rozwiązanie typu Managed (SCC, Secret Manager, Cloud KMS), a unikaj rozwiązań self-managed, chyba że pytanie wyraźnie wymaga dostosowania niskopoziomowego.

Haczyki egzaminacyjne (Exam Traps):
- Pułapka IAM: Pytania o uprawnienia często sugerują 'Project Owner' – zawsze szukaj 'Least Privilege' (np. 'Role: Secret Manager Secret Accessor').
- Pułapka Sieciowa: Często mylone są VPC Peering (wydajność) oraz VPN (szyfrowanie/on-premise).

Głębokie wyjaśnienie techniczne:
Rozwiązanie bazuje na GCP Shared Responsibility Model. Google zarządza bezpieczeństwem infrastruktury (Physical, Network, Host), podczas gdy administrator zarządza tożsamością (IAM), danymi (Encryption, Cloud KMS) i regułami dostępu (VPC Firewall).

Analiza i Podsumowanie (AI)

Kluczowe zagadnienia

Sugerowana odpowiedź: D

Analiza strategiczna: To pytanie testuje architekturę sieciową "Enterprise". Duże organizacje często wymuszają tzw. "Forced Tunneling", aby cały ruch internetowy był analizowany przez korporacyjny stos bezpieczeństwa (np. proxy, firewalle) przed wyjściem w świat. Cloud Interconnect jest "autostradą" niezbędną dla takiej skali.

Dodatkowe wskazówki

  • Przy forced tunneling musisz uważać na routing – jeśli zablokujesz drogę powrotną, zepsujesz komunikację z aplikacjami.
  • Natywne usługi Google (jak Cloud NAT) są często wybierane jako prostsza alternatywa dla on-premise firewalli, jeśli wymagania bezpieczeństwa na to pozwalają.
