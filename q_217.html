Question 217 / 361

You are routing all your internet facing traffic from Google Cloud through your on-premises internet connection. You want to accomplish this goal securely and with the highest bandwidth possible. What should you do?

  • A. Create an HA VPN connection to Google Cloud. Replace the default 0.0.0.0/0 route.
  • B. Create a routing VM in Compute Engine. Configure the default route with the VM as the next hop.
  • C. Configure Cloud Interconnect with HA VPN. Replace the default 0.0.0.0/0 route to an on-premises destination.
  • D. Configure Cloud Interconnect and route traffic through an on-premises firewall.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
D. Configure Cloud Interconnect and route traffic through an on-premises firewall.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Odpowiedź D jest prawidłowa, ponieważ Cloud Interconnect zapewnia bezpośrednie, fizyczne połączenie o najwyższej możliwej przepustowości (do 100 Gbps na łącze) i najniższych opóźnieniach między Google Cloud a lokalną serwerownią. 

Mechanizm działania:
a. Firma chce kierować cały ruch internetowy (0.0.0.0/0) z GCP przez swoje lokalne zabezpieczenia (on-premises firewall).
b. Aby to osiągnąć, w sieci VPC instalowana jest trasa domyślna (default route) wskazująca jako następny krok (next hop) połączenie hybrydowe do lokalnej serwerowni.
c. Cloud Interconnect (w przeciwieństwie do VPN) zapewnia najwyższą przepustowość (highest bandwidth) i stabilność, ponieważ nie przesyła danych przez publiczny internet. Ruch trafia bezpośrednio z sieci Google do fizycznego firewalla on-premises, gdzie jest filtrowany i wypuszczany do internetu.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
A. Create an HA VPN connection to Google Cloud. Replace the default 0.0.0.0/0 route.
   * Dlaczego nieprawidłowa: Cloud VPN (nawet w wersji High Availability) ma ograniczenia przepustowości (standardowo 3 Gbps na tunel). Nie zapewnia najwyższej możliwej przepustowości (highest bandwidth) w porównaniu z Cloud Interconnect.
B. Create a routing VM in Compute Engine. Configure the default route with the VM as the next hop.
   * Dlaczego nieprawidłowa: Użycie pojedynczej maszyny VM jako routera tworzy wąskie gardło wydajnościowe (bottleneck) i pojedynczy punkt awarii (single point of failure). Nie realizuje hybrydowego przekierowania ruchu przez on-premises w sposób stabilny i wydajny.
C. Configure Cloud Interconnect with HA VPN. Replace the default 0.0.0.0/0 route to an on-premises destination.
   * Dlaczego nieprawidłowa: Chociaż Cloud Interconnect z HA VPN (tzw. VPN over Interconnect) zapewnia szyfrowanie IPsec, to dodanie warstwy VPN na fizycznym łączu Interconnect drastycznie ogranicza przepustowość do limitów tuneli VPN oraz narzuca narzut na procesowanie pakietów. Pytanie prosi o najwyższą wydajność/przepustowość, co wskazuje na czysty Cloud Interconnect.

4. Wskazówki, hinty, tips and tricks:
* Najwyższa wydajność i przepustowość łącza hybrydowego w GCP -> Zawsze **Cloud Interconnect**.
* Przekierowanie ruchu internetowego do sieci lokalnej (forced tunneling) realizuje się poprzez ogłoszenie trasy `0.0.0.0/0` przez protokół BGP z lokalnej serwerowni do GCP Cloud Router.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
* Highest bandwidth connection to on-premises -> Cloud Interconnect.
* Route traffic to on-premises -> Advertise 0.0.0.0/0 route via BGP / Cloud Interconnect.
