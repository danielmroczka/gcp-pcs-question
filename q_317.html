Question 317 / 361

You work for a large organization that recently implemented a 100GB Cloud Interconnect connection between your Google Cloud and your on-premises edge router. While routinely checking the connectivity, you noticed that the connection is operational but there is an error message that indicates MACsec is operationally down. You need to resolve this error. What should you do?

  • A. Ensure that the Cloud Interconnect connection supports MACsec.
  • B. Ensure that the on-premises router is not down.
  • C. Ensure that the active pre-shared key created for MACsec is not expired on both the on-premises and Google edge routers.
  • D. Ensure that the active pre-shared key matches on both the on-premises and Google edge routers.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

✅ PRAWIDŁOWA ODPOWIEDŹ: D

Prawidłowa odpowiedź: D – Ensure that the active pre-shared key matches on both the on-premises and Google side.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO D JEST PRAWIDŁOWE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
MACsec (IEEE 802.1AE) szyfruje ruch na warstwie Ethernet (Layer 2). Wymaga że pre-shared key (CAK – Connectivity Association Key) musi być IDENTYCZNY po obu stronach połączenia. Jeśli klucze nie pasują, sesja MACsec nie nawiązuje szyfrowania, co powoduje problemy z łącznością. To najczęstsza przyczyna awarii MACsec.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO INNE OPCJE SĄ BŁĘDNE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. ❌ "Ensure Cloud Interconnect supports MACsec" – Cloud Interconnect od 2021 roku wspiera MACsec dla 100G połączeń. To sprawdzenie przed wdrożeniem, nie diagnoza istniejącego problemu.
B. ❌ "Ensure on-premises router is not down" – ogólna diagnoza sieciowa. Pytanie dotyczy problemu z MACsec, nie ogólnej łączności.
C. ❌ "Ensure pre-shared key is not expired" – wygaśnięcie klucza to jeden przypadek, ale D jest bardziej precyzyjne i obejmuje też sytuację "klucz się nie zgadza". Expired key ⊂ non-matching key.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WSKAZÓWKI EGZAMINACYJNE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• MACsec = Layer 2 encryption dla Cloud Interconnect.
• Pre-shared key MUSI być identyczny po obu stronach.
• MACsec problemy = prawie zawsze problem z kluczami.
• Cloud Interconnect MACsec wymaga 100Gbps połączenia (nie 10G).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
REGUŁY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• MACsec troubleshooting = sprawdź zgodność pre-shared key po obu stronach.
• MACsec ≠ IPsec (IPsec = Layer 3, MACsec = Layer 2).
