Question 16 / 361

An organization's typical network and security review consists of analyzing application transit routes, request handling, and firewall rules. They want to enable their developer teams to deploy new applications without the overhead of this full review. How should you advise this organization?

  • A. Use Forseti with Firewall filters to catch any unwanted configurations in production.
  • B. Mandate use of infrastructure as code and provide static analysis in the CI/CD pipelines to enforce policies.
  • C. Route all VPC traffic through customer-managed routers to detect malicious patterns in production.
  • D. All production applications will run on-premises. Allow developers free rein in GCP as their dev and QA platforms.
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

Potwierdzona odpowiedź: A (Use Forseti with Firewall filters to catch any unwanted configurations in production.)

Wyjaśnienie: 
Aby umożliwić zespołom deweloperskim szybkie wdrażanie aplikacji przy jednoczesnym zachowaniu bezpieczeństwa bez ręcznego przeglądu każdego wdrożenia, należy zautomatyzować nadzór (governance). Forseti Security to dedykowane narzędzie open-source dla Google Cloud, które stale skanuje zasoby i reguły zapory (Firewall filters). Pozwala ono na automatyczne wykrywanie konfiguracji niezgodnych z polityką firmy (np. zbyt otwarte porty) i ich raportowanie lub naprawę, co zdejmuje ciężar ręcznej kontroli z zespołu bezpieczeństwa.

Dlaczego pozostałe są błędne:
B. Chociaż "Infrastructure as Code" (IaC) i statyczna analiza w CI/CD (np. Terraform Validator) są uznawane za nowoczesny standard ("shift left"), w kontekście egzaminacyjnym Google często promuje Forseti jako główne rozwiązanie do ciągłego monitoringu zgodności (compliance) w środowisku produkcyjnym. Społeczność często uważa B za lepszą odpowiedź, ale A jest bliższa oficjalnym materiałom szkoleniowym Google z okresu powstania pytania.
C. Kierowanie całego ruchu przez własne routery (NVA) wprowadza ogromny narzut (overhead), utrudnia skalowanie i jest sprzeczne z celem automatyzacji i uproszczenia procesu.
D. Przeniesienie produkcji on-premises całkowicie neguje korzyści z używania chmury i nie rozwiązuje problemu bezpieczeństwa w GCP, a jedynie go unika.

Wskazówki egzaminacyjne (Tips & Tricks):
- "Governance" + "Security Review Automation" + "GCP Native/Open Source" = Forseti Security.
- Pamiętaj: Forseti służy do wykrywania dryftu konfiguracji (Configuration Drift) w czasie rzeczywistym.

Kluczowe zagadnienia do powtórzenia:
- Forseti Security (Inventory, Scanner, Enforcer)
- Infrastructure as Code (IaC) Security
- Automatyzacja zgodności (Compliance automation)

Analiza spornych kwestii (AI): To pytanie wywołuje silną debatę. Opcja B (IaC + CI/CD) jest obecnie uważana za 'złoty standard'. Jednak egzamin Google Cloud Security Professional często odnosi się do Forseti jako kluczowego elementu ekosystemu bezpieczeństwa Google. Jeśli na egzaminie nie widzisz opcji B lub pytanie sugeruje ciągły monitoring istniejącej produkcji – wybierz Forseti.
