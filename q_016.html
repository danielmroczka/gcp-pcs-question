Question 16 / 361

An organization's typical network and security review consists of analyzing application transit routes, request handling, and firewall rules. They want to enable their developer teams to deploy new applications without the overhead of this full review. How should you advise this organization?

  • A. Use Forseti with Firewall filters to catch any unwanted configurations in production.
  • B. Mandate use of infrastructure as code and provide static analysis in the CI/CD pipelines to enforce policies.
  • C. Route all VPC traffic through customer-managed routers to detect malicious patterns in production.
  • D. All production applications will run on-premises. Allow developers free rein in GCP as their dev and QA platforms.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

**Potwierdzona odpowiedź: B**

**Reguła Egzaminacyjna (Exam Rule):**
Zasada "Shift-Left Security" polega na przesunięciu kontroli bezpieczeństwa na jak najwcześniejszy etap cyklu życia oprogramowania (CI/CD), zamiast polegania na reaktywnych audytach w środowisku produkcyjnym.

**Haczyki egzaminacyjne (Exam Traps):**
- A: Forseti jest narzędziem do audytu, a nie do zapobiegania błędom przed wdrożeniem.
- C: Routing przez zewnętrzne urządzenia jest kosztowny i skomplikowany, nie rozwiązuje problemu wdrożeń.
- D: Przeniesienie produkcji na on-premises zaprzecza idei korzystania z chmury i nie rozwiązuje problemu bezpieczeństwa w GCP.

**Głębokie wyjaśnienie techniczne:**
W modelu współdzielonej odpowiedzialności, GCP dba o bezpieczeństwo infrastruktury ("of the cloud"), ale klient jest w pełni odpowiedzialny za konfigurację swoich zasobów ("in the cloud"). Wprowadzenie analizy statycznej (np. Terraform-compliance, Checkov) w potoku CI/CD wymusza stosowanie polityk bezpieczeństwa (Governance as Code) przed samym wdrożeniem, co eliminuje błędy konfiguracji (np. otwarte porty firewall) na poziomie projektu, zanim zasoby zostaną stworzone.

Analiza i Wyjaśnienie

Sugerowana odpowiedź: B

Analiza: W nowoczesnych egzaminach GCP (Cloud Security Professional) podejście IaC/CI/CD (B) jest uznawane za nadrzędną metodę "Security by Design" w porównaniu do reaktywnego Forseti (A).
