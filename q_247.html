Question 247 / 361

You run a web application on top of Cloud Run that is exposed to the internet with an Application Load Balancer. You want to ensure that only privileged users from your organization can access the application. The proposed solution must support browser access with single sign-on. What should you do?

  • A. Change Cloud Run configuration to require authentication. Assign the role of Cloud Run Invoker to the group of privileged users.
  • B. Create a group of privileged users in Cloud Identity. Assign the role of Cloud Run User to the group directly on the Cloud Run service.
  • C. Change the Ingress Control configuration of Cloud Run to internal and create firewall rules to allow only access from known IP addresses.
  • D. Activate Identity-Aware Proxy (IAP) on the Application Load Balancer backend. Assign the role of IAP-secured Web App User to the group of privileged users.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
D. Activate Identity-Aware Proxy (IAP) on the Application Load Balancer backend. Assign the role of IAP-secured Web App User to the groups of privileged users.

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Odpowiedź D jest prawidłowa, ponieważ włączenie Identity-Aware Proxy (IAP) na poziomie zewnętrznego Load Balancera (Application Load Balancer) chroniącego usługę Cloud Run w pełni realizuje wymaganie uwierzytelniania użytkowników za pomocą przeglądarki z obsługą Single Sign-On (SSO).

Szczegóły mechanizmu:
a. **Integracja z Load Balancerem:** Ruch z internetu trafia do Load Balancera, który przekazuje go do backendu Cloud Run.
b. **Wymuszenie logowania (IAP):** Po aktywacji IAP na usłudze backendu, IAP przechwytuje żądania przeglądarki i automatycznie przekierowuje użytkowników do centralnego portalu logowania (Google SSO / Cloud Identity).
c. **Kontrola dostępu:** Tylko użytkownicy posiadający rolę `roles/iap.httpsResourceAccessor` (IAP-secured Web App User) mogą przejść dalej. Cloud Run może być wówczas skonfigurowany tak, by akceptować ruch wyłącznie pochodzący z Load Balancera/IAP, co zapobiega bezpośrednim próbom dostępu.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
A. Change Cloud Run configuration to require authentication. Assign the role of Cloud Run Invoker to the group...
   * Dlaczego nieprawidłowa: Wymuszenie autoryzacji IAM bezpośrednio na poziomie Cloud Run (`require-authentication`) jest przeznaczone dla komunikacji między usługami (service-to-service) za pomocą tokenów kont serwisowych (Bearer tokens). Nie obsługuje ono w przyjazny sposób standardowego logowania użytkowników przez przeglądarkę za pomocą formularza SSO.
B. Create a group of privileged users in Cloud Identity. Assign the role of Cloud Run User to the group...
   * Dlaczego nieprawidłowa: Rola `roles/run.user` (Cloud Run User) daje uprawnienia administracyjne do zarządzania i wdrażania usług Cloud Run. Nie służy do autoryzacji użytkowników końcowych, którzy mają jedynie wywoływać aplikację webową (do tego służy rola Invoker, ale z ograniczeniami opisanymi w punkcie A).
C. Change the Ingress Control configuration of Cloud Run to internal and create firewall rules...
   * Dlaczego nieprawidłowa: Ustawienie Ingress na `internal` uniemożliwia bezpośredni dostęp z internetu, ale zapora sieciowa (firewall rules) w GCP nie filtruje tożsamości użytkowników i nie oferuje mechanizmu SSO dla przeglądarek. Ponadto Cloud Run nie jest bezpośrednio chroniony tradycyjnymi regułami zapory sieciowej VPC na poziomie portów w taki sposób jak maszyny VM.

4. Wskazówki, hinty, tips and tricks:
* Ochrona publicznych aplikacji webowych (browser access + SSO) w GCP (Cloud Run, GKE, GCE) -> Zawsze **Identity-Aware Proxy (IAP)** na **HTTPS Load Balancerze**.
* IAP zarządza sesjami użytkowników w przeglądarce i integruje się z systemami Identity Provider (IdP) firmy.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
* Cloud Run / App Engine + browser access with SSO -> Identity-Aware Proxy (IAP) on Application Load Balancer backend.
