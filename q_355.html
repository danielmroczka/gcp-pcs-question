Question 355 / 361

You work at a company in a regulated industry and are responsible for ongoing security of the Cloud environment. You need to prevent and detect misconfigurations in a particular folder based on specific compliance policies. You need to adhere to industry-specific compliance policies and policies that are internal to your company. What should you do?

  • A. Create a Posture file by using custom and predefined SHA or organization policies. Enforce the posture on the folder level.
  • B. Create custom organization policies that follow specific business requirements. Enforce the policies on the folder level.
  • C. Enable Assured Workloads on the folder level, with the specific control bundle appropriate for your industry's regulations.
  • D. Use Workload Manager with custom Rego policies to continuously scan the environment for misconfigurations on the folder level.
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

✅ PRAWIDŁOWA ODPOWIEDŹ: A

Prawidłowa odpowiedź: A – Create a Posture file by using custom and predefined SHA or organization policies. Enforce the posture on the folder. Configure monitoring and drift detection.

DLACZEGO A JEST PRAWIDŁOWE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Security Posture w SCC (Security Command Center) to kompleksowe podejście:
- Posture file = deklaratywna definicja pożądanego stanu bezpieczeństwa.
- Zawiera: custom + predefined SHA policies i org policies.
- Enforcement + drift detection = wykrycie i alert gdy konfiguracja odbiega od pożądanego stanu.
- Stosowane na folderze = granularne, nie wpływa na całą organizację.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO INNE OPCJE SĄ BŁĘDNE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
B. ❌ Custom org policies tylko = brak SHA policies i drift detection. Nie monitoruje odchyleń od pożądanego stanu.
C. ❌ Assured Workloads = gotowe compliance bundles dla regulowanych branż (FedRAMP, HIPAA). Nie obsługuje custom business requirements.
D. ❌ Workload Manager z Rego = Workload Manager jest dla SAP/enterprise workloads, nie dla custom security posture.

• Posture = łączy org policies + SHA w jednym miejscu.
• "Prevent AND detect misconfigurations" = posture enforcement + drift detection.
• Assured Workloads ≠ custom requirements (Assured = gotowe bundles regulacyjne).

Kluczowe zagadnienia

Sugerowana odpowiedź: A

Analiza strategiczna: Pytanie o nowoczesne podejście do zarządzania "Posture Management" w GCP. SCC Postures integruje polityki (prewencja) i reguły SHA (detekcja), co jest optymalnym rozwiązaniem do utrzymania bezpieczeństwa w skali folderów/projektów.
