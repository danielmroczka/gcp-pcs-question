Question 342 / 361

Your company is in a regulated industry that requires low overhead encryption using private connectivity from on-premises data centers to Google Cloud. You need to establish connectivity and ensure high availability across multiple regions. What should you do?

  • A. Set up two pairs of HA VPNs using IPSec from the data centers in multiple regions.
  • B. Set up pairs of Cloud Interconnect connections to your data centers in multiple regions, and employ MACSec encryption.
  • C. Set up L2TP encryption over pairs of dedicated Cloud Interconnect connections from the data centers in multiple regions.
  • D. Set up IPSec encryption over Partner Interconnect connections from your data centers in multiple regions.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

✅ PRAWIDŁOWA ODPOWIEDŹ: B

Prawidłowa odpowiedź: B – Set up pairs of Cloud Interconnect connections to your data centers in multiple regions, and employ MACsec encryption.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO B JEST PRAWIDŁOWE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Wymagania: "low overhead encryption" + "private connectivity" + "high availability" + "multiple regions". Cloud Interconnect + MACsec:
- Interconnect = prywatne połączenie (nie przez Internet).
- MACsec = Layer 2 encryption z minimalnym narzutem (hardware-level, nie softwarowy).
- Pary połączeń = HA.
- Multiple regions = pokrycie geograficzne.
MACsec ma najmniejszy overhead z dostępnych opcji szyfrowania.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO INNE OPCJE SĄ BŁĘDNE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. ❌ HA VPN przez Internet = nie "private connectivity". VPN przechodzi przez publiczny Internet.
C. ❌ L2TP = starszy protokół z wyższym narzutem niż MACsec. Nie jest standardem dla Cloud Interconnect.
D. ❌ IPSec nad Partner Interconnect = wyższy overhead niż MACsec (IPSec = L3 software encryption). Partner Interconnect ≠ Dedicated Interconnect.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WSKAZÓWKI EGZAMINACYJNE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• "Low overhead encryption" = MACsec (Layer 2, hardware).
• "Private connectivity" = Cloud Interconnect (nie VPN przez Internet).
• MACsec > IPSec > SSL/TLS (pod względem narzutu).
• HA = pary połączeń Interconnect.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
REGUŁY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Low overhead + private = Cloud Interconnect + MACsec.
• VPN = przez Internet (nie "private" w sensie L2).
