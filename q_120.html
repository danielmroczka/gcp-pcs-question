Question 120 / 361

You need to enable VPC Service Controls and allow changes to perimeters in existing environments without preventing access to resources. Which VPC Service Controls mode should you use?

  • A. Cloud Run
  • B. Native
  • C. Enforced
  • D. Dry run
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
D. Dry run

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Wymaganiem jest przetestowanie zmian w konfiguracji perymetrów bezpieczeństwa VPC Service Controls w działającym środowisku produkcyjnym bez ryzyka zablokowania dostępu do zasobów dla uprawnionych użytkowników i aplikacji:
- Tryb "Dry run" (próby/symulacji) w VPC Service Controls pozwala na weryfikację działania reguł perymetru w tle. Kiedy zapytanie narusza zasady perymetru, VPC Service Controls nie blokuje tego zapytania, lecz jedynie rejestruje to zdarzenie w logach (Cloud Audit Logs) jako potencjalne naruszenie. Dzięki temu administratorzy mogą przeanalizować logi, wykryć ewentualne fałszywe alarmy i dostosować reguły przed pełnym wdrożeniem zabezpieczeń.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- A. Cloud Run: Jest to w pełni zarządzana platforma serverless do uruchamiania kontenerów, a nie tryb działania usługi VPC Service Controls.
- B. Native: Taki tryb nie istnieje w specyfikacji konfiguracji perymetru VPC Service Controls.
- C. Enforced: W tym trybie (wymuszenia) wszelkie próby dostępu naruszające reguły perymetru są natychmiast blokowane. Wdrożenie zmian bezpośrednio w trybie Enforced w działającym środowisku stwarza wysokie ryzyko przestojów i awarii aplikacji.

4. Wskazówki, hinty, tips and tricks:
- Zawsze, gdy mowa o bezpiecznym wdrażaniu, testowaniu lub modyfikowaniu perymetrów VPC Service Controls w działającym środowisku produkcyjnym bez zakłócania ruchu, poprawną odpowiedzią jest tryb **Dry run**.
- Analiza logów z trybu dry run pozwala na bezbłędne przejście do trybu Enforced.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Testowanie perymetru VPC SC bez blokowania ruchu -> Dry run mode.
- Aktywna blokada dostępu -> Enforced mode.

6. Dodatkowe źródła i dokumentacja:
- VPC Service Controls Dry run mode: https://cloud.google.com/vpc-service-controls/docs/dry-run-mode
