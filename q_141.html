Question 141 / 361

You have been tasked with configuring Security Command Center for your organization's Google Cloud environment. Your security team needs to receive alerts of potential crypto mining in the organization's compute environment and alerts for common Google Cloud misconfigurations that impact security. Which Security Command Center features should you use to configure these alerts? (Choose two.)

  • A. Event Threat Detection
  • B. Container Threat Detection
  • C. Security Health Analytics
  • D. Cloud Data Loss Prevention
  • E. Google Cloud Armor
Show Suggested Answer Hide Answer
Suggested Answer: AC

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
A. Event Threat Detection
C. Security Health Analytics

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Wymagane jest skonfigurowanie usługi Security Command Center (SCC) do wysyłania alertów o: 1) potencjalnym kopaniu kryptowalut (cryptomining) oraz 2) typowych błędach konfiguracyjnych w zasobach GCP:
- A (Event Threat Detection): ETD to wbudowana usługa SCC, która analizuje strumienie logów (Cloud Audit Logs, VPC Flow Logs itp.) i wykrywa aktywne zagrożenia, takie jak uruchomienie oprogramowania do kopania kryptowalut w środowisku Compute Engine, próby brute-force lub eksfiltracja danych.
- C (Security Health Analytics): SHA to mechanizm skanowania konfiguracji w SCC. Automatycznie wykrywa typowe luki i błędy konfiguracyjne zasobów GCP (np. publicznie dostępne kubełki GCS, brak włączonej ochrony przed usuwaniem, zbyt szeroko otwarte reguły firewalla).

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- B. Container Threat Detection: Choć potrafi wykryć cryptomining wewnątrz kontenerów GKE na poziomie jądra systemu operacyjnego, nie analizuje i nie wykrywa ogólnych błędów konfiguracyjnych chmury w organizacji.
- D. Cloud Data Loss Prevention (DLP): Służy do skanowania, wykrywania i maskowania danych wrażliwych (PII) w plikach i bazach danych, nie wykrywa ataków cryptomining ani błędów konfiguracyjnych infrastruktury sieciowej.
- E. Google Cloud Armor: Jest to zapora sieciowa WAF chroniąca przed atakami internetowymi, nie jest modułem detekcyjnym wewnątrz Security Command Center.

4. Wskazówki, hinty, tips and tricks:
- Zapamiętaj podział modułów w SCC Premium:
  - **Security Health Analytics (SHA)** -> Wykrywa błędy konfiguracji (Misconfigurations) chmury.
  - **Event Threat Detection (ETD)** -> Analizuje logi i wykrywa aktywne zagrożenia (Threats, np. cryptomining, malware).
  - **Container Threat Detection** -> Analizuje stan wewnątrz uruchomionych kontenerów GKE.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- SCC + misconfigurations -> Security Health Analytics.
- SCC + cryptomining / zagrożenia w logach -> Event Threat Detection.
