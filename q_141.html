Question 141 / 361

SCC configuration. Alerts for crypto mining and misconfigurations. Which two features?

  • A. Event Threat Detection
  • B. Container Threat Detection
  • C. Security Health Analytics
  • D. Cloud DLP
  • E. Cloud Armor
Show Suggested Answer Hide Answer
Suggested Answer: AC

Wyjaśnienie

Odpowiedź: AC.

Wyjaśnienie (Dlaczego poprawna):
A. Event Threat Detection: Analizuje logi (np. Cloud Audit Logs, VPC Flow Logs) w czasie rzeczywistym i wykrywa wzorce charakterystyczne dla zagrożeń takich jak właśnie crypto mining, brute force czy wycieki danych.
C. Security Health Analytics: Skupia się na wykrywaniu błędnych konfiguracji infrastruktury (misconfigurations), np. otwartych portów SSH na cały świat czy braku wersjonowania bucketów.

Dlaczego inne są błędne:
B. Container Threat Detection: Monitoruje wnętrze działającego kontenera (np. próba odczytu pamięci przez obcy proces). Jest to Premium, ale A i C pokrywają szerszy zakres 'misconfigurations' i 'threats' wymienionych w pytaniu.
D. Cloud DLP: Szuka danych wrażliwych, nie wykrywa ataków typu mining.
E. Cloud Armor: Chroni aplikacje webowe przed atakami z zewnątrz.

Konsensus społeczności ExamTopics: Silne poparcie dla AC. To dwa fundamentalne filary SCC Premium.
