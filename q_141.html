Question 141 / 361

You have been tasked with configuring Security Command Center for your organization's Google Cloud environment. Your security team needs to receive alerts of potential crypto mining in the organization's compute environment and alerts for common Google Cloud misconfigurations that impact security. Which Security Command Center features should you use to configure these alerts? (Choose two.)

  • A. Event Threat Detection
  • B. Container Threat Detection
  • C. Security Health Analytics
  • D. Cloud Data Loss Prevention
  • E. Google Cloud Armor
Show Suggested Answer Hide Answer
Suggested Answer: AC

Wyjaśnienie

Potwierdzona odpowiedź: AC (A. Event Threat Detection, C. Security Health Analytics).

Wyjaśnienie:
- A. Event Threat Detection (ETD): Jest to funkcja Security Command Center (SCC), która automatycznie skanuje logi (Cloud Audit Logs, VPC Flow Logs itp.) pod kątem znanych zagrożeń. ETD potrafi wykryć ślady kopania kryptowalut (cryptomining), np. komunikację z serwerami mining pools lub adresami C2.
- C. Security Health Analytics (SHA): Jest to skaner podatności SCC, który automatycznie wykrywa typowe błędy konfiguracji (misconfigurations) w środowisku Google Cloud, takie jak publicznie dostępne buckety GCS, brak włączonego logowania czy słabe reguły firewall.

Dlaczego pozostałe są błędne:
- B. Container Threat Detection: Chociaż potrafi wykryć kopanie kryptowalut wewnątrz kontenerów GKE, ETD (A) jest rozwiązaniem szerszym, monitorującym całe środowisko compute (VM i kontenery) na poziomie logów zdarzeń. SHA (C) jest niezbędne do spełnienia drugiej części wymagania (misconfigurations).
- D. Cloud Data Loss Prevention (DLP): Służy do wykrywania i ochrony danych wrażliwych (PII), a nie do wykrywania zagrożeń typu cryptomining czy błędów konfiguracji infrastruktury.
- E. Google Cloud Armor: Jest to firewall aplikacyjny (WAF) i ochrona przed DDoS. Nie służy do wykrywania kopania kryptowalut ani audytowania konfiguracji zasobów Google Cloud.

Wskazówki egzaminacyjne (Tips & Tricks):
- "Threats" (zagrożenia, np. mining, malware, phishing) = Event Threat Detection.
- "Misconfigurations" (błędy konfiguracji, np. public buckets, open ports) = Security Health Analytics.
- Obie te usługi są częścią Security Command Center (SCC).

Kluczowe zagadnienia do powtórzenia:
- Moduły Security Command Center (SHA, ETD, Container Threat Detection, VM Threat Detection).
- Różnica między detekcją zagrożeń a skanowaniem konfiguracji.
- Poziomy SCC (Standard vs Premium).
