Question 130 / 361

You plan to use a Google Cloud Armor policy to prevent common attacks such as cross-site scripting (XSS) and SQL injection (SQLi) from reaching your web application's backend. What are two requirements for using Google Cloud Armor security policies? (Choose two.)

  • A. The load balancer must be an external SSL proxy load balancer.
  • B. Google Cloud Armor Policy rules can only match on Layer 7 (L7) attributes.
  • C. The load balancer must use the Premium Network Service Tier.
  • D. The backend service's load balancing scheme must be EXTERNAL.
  • E. The load balancer must be an external HTTP(S) load balancer.
Show Suggested Answer Hide Answer
Suggested Answer: DE

Wyjaśnienie

Potwierdzona odpowiedź: DE (D. The backend service's load balancing scheme must be EXTERNAL, E. The load balancer must be an external HTTP(S) load balancer.)

Wyjaśnienie:
Google Cloud Armor to usługa WAF (Web Application Firewall) i ochrony przed DDoS, która integruje się z brzegowymi load balancerami Google Cloud. Aby korzystać z pełnej gamy polityk bezpieczeństwa Cloud Armor (w tym reguł WAF chroniących przed SQLi/XSS), muszą być spełnione dwa kluczowe wymogi architektoniczne:
1. Load balancer musi być typu External HTTP(S) (E), ponieważ tylko on operuje na warstwie 7 (aplikacji) i pozwala na inspekcję treści żądań.
2. Schemat równoważenia obciążenia (load balancing scheme) w usłudze backendowej musi być ustawiony na EXTERNAL (D). Cloud Armor jest przypisywany bezpośrednio do Backend Service.

Dlaczego pozostałe odpowiedzi są niepoprawne:
- A: SSL Proxy Load Balancer działa na warstwie 4 (TCP). Chociaż Cloud Armor oferuje dla niego podstawową ochronę przed DDoS, nie wspiera na nim zaawansowanych reguł WAF (L7), o które pyta zadanie (XSS/SQLi).
- B: Reguły Cloud Armor mogą dopasowywać ruch zarówno na podstawie atrybutów warstwy 7 (L7 - np. nagłówki, cookies), jak i warstwy 3/4 (L3/L4 - np. adresy IP).
- C: Korzystanie z Premium Network Service Tier jest zalecane i domyślne dla globalnych load balancerów, ale nie jest sztywnym wymogiem technicznym specyficznym tylko dla działania Cloud Armor.

Wskazówki i triki (Tips & Tricks):
- "WAF rules" + "XSS/SQLi" = Zawsze myśl o External HTTP(S) Load Balancer + Cloud Armor.
- Pamiętaj, że Cloud Armor nie chroni load balancerów wewnętrznych (Internal LB).

Praktyczne informacje na egzamin:
- Cloud Armor "Security Policy" przypisujesz do "Backend Service".
- Możesz używać reguł w trybie "preview", aby testować ich wpływ przed faktycznym blokowaniem ruchu.

Analiza i Wyjaśnienie

Sugerowana odpowiedź: DE

Głęboka analiza: Cloud Armor jest usługą brzegową (Edge), co oznacza, że ruch jest filtrowany zanim jeszcze dotrze do Twojej sieci VPC. Jest to kluczowe dla ochrony przed wolumetrycznymi atakami DDoS. W przypadku ochrony WAF (warstwa 7), Cloud Armor analizuje strukturę żądania HTTP, szukając znanych wzorców ataków zdefiniowanych w regułach prekonfigurowanych (np. na podstawie CRS - Core Rule Set projektu OWASP).
