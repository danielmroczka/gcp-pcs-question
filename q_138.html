Question 138 / 361

A database administrator notices malicious activities within their Cloud SQL instance. The database administrator wants to monitor the API calls that read the configuration or metadata of resources. Which logs should the database administrator review?

  • A. Admin Activity
  • B. System Event
  • C. Access Transparency
  • D. Data Access
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
D. Data Access

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Administrator bazy danych chce monitorować połączenia/wywołania API, które odczytują konfigurację lub metadane zasobów Cloud SQL (np. operacje typu get lub list):
- W Google Cloud logi audytowe (Cloud Audit Logs) dzielą się na cztery kategorie. Operacje odczytu metadanych oraz konfiguracji zasobów (np. pobranie szczegółów instancji bazy danych) są rejestrowane w logach **Data Access audit logs** (kategoria: Admin Read). Logi te rejestrują również odczyty i zapisy samych danych użytkownika wewnątrz usług.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- A. Admin Activity logs: Rejestrują wyłącznie operacje zapisu (modyfikacji, tworzenia, usuwania) metadanych i konfiguracji (np. utworzenie nowej bazy danych Cloud SQL, zmiana typu instancji). Nie logują operacji odczytu (read-only).
- B. System Event logs: Rejestrują działania administracyjne podejmowane automatycznie przez systemy Google Cloud (np. automatyczna migracja na inny host), a nie działania użytkowników czy administratorów.
- C. Access Transparency logs: Rejestrują zdarzenia, w których pracownicy wsparcia technicznego Google uzyskiwali dostęp do zasobów klienta w celu rozwiązania zgłoszenia serwisowego.

4. Wskazówki, hinty, tips and tricks:
- Zapamiętaj podział logów audytowych:
  - **Admin Activity** -> Operacje modyfikujące (write) konfigurację zasobów (np. `create`, `update`, `delete`). Zawsze włączone.
  - **Data Access** -> Operacje odczytujące (read) konfigurację zasobów (np. `get`, `list`) oraz operacje na danych użytkownika. Domyślnie wyłączone (oprócz BigQuery).
  - **Access Transparency** -> Działania inżynierów Google.

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Odczyt konfiguracji / metadanych zasobu -> Data Access logs.
- Modyfikacja / zapis konfiguracji zasobu -> Admin Activity logs.

6. Dodatkowe źródła i dokumentacja:
- Cloud Audit Logs types: https://cloud.google.com/logging/docs/audit#types
