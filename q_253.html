Question 253 / 361

You have a chatbot application that collects PII from users in real-time. You need to ensure that the chatbot does not store PII in its logs or training data, while maintaining the functionality of the chatbot. What should you do?

  • A. Use KMS encryption to encrypt all messages.
  • B. Use the Cloud Data Loss Prevention (Cloud DLP) API to scan and de-identify PII in real-time for input and output messages.
  • C. Configure VPC Service Controls to prevent the bot from accessing storage.
  • D. Use third-party market place tools for PII detection.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Poprawna odpowiedź: B (Use the Cloud Data Loss Prevention (Cloud DLP) API to scan and de-identify PII in real-time for input and output messages.)

Dlaczego ta odpowiedź jest poprawna:
- Cloud Data Loss Prevention (Cloud DLP): Jest to dedykowana usługa Google Cloud do odkrywania, klasyfikowania i ochrony danych wrażliwych (PII).
- Przetwarzanie w czasie rzeczywistym: DLP API oferuje funkcję `deidentifyContent` (dla tekstu), która pozwala na "redakcję" (usuwanie) lub maskowanie (zamianę na tokeny) danych wrażliwych w locie. Idealnie nadaje się do potoków chatbotowych:
    1. Chatbot otrzymuje wiadomość -> wysyłasz tekst do DLP API (maskowanie PII) -> przesyłasz zanonimizowany tekst do modelu AI.
    2. Model AI generuje odpowiedź -> przesyłasz odpowiedź do DLP API (kontrola PII) -> wyświetlasz bezpieczną odpowiedź użytkownikowi.

Analiza niepoprawnych odpowiedzi:
- A. Szyfrowanie KMS: Szyfruje dane "at rest", ale nie chroni przed przesyłaniem jawnych danych PII do modelu AI (gdzie mogłyby zostać np. użyte do dotrenowania modelu).
- C. VPC Service Controls: VPC SC chroni przed eksfiltracją (wynoszeniem danych poza projekt), ale nie modyfikuje zawartości wiadomości chatbotowych pod kątem PII.
- D. Market place tools: Używanie zewnętrznych narzędzi jest mniej wydajne i trudniejsze w integracji z usługami AI Google niż natywne DLP API.

Wskazówki i triki (Tips & Tricks):
- "Chatbot" / "User interaction" / "Input and Output" + "No PII" = Cloud DLP API (De-identification).
- Pamiętaj: DLP API działa na strumieniach tekstowych.

Praktyczne informacje na egzamin:
- Zapamiętaj, że DLP API posiada predefiniowane "InfoTypes" (np. PESEL, numer karty, adres e-mail), które automatycznie wykrywa.
- DLP API oferuje również "fuzzing" i "bucketing" (uogólnianie danych) dla potrzeb analitycznych.
