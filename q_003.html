Question 3 / 361

A customer needs an alternative to storing their plain text secrets in their source-code management (SCM) system. How should the customer achieve this using Google Cloud Platform?

  • A. Use Cloud Source Repositories, and store secrets in Cloud SQL.
  • B. Encrypt the secrets with a Customer-Managed Encryption Key (CMEK), and store them in Cloud Storage.
  • C. Run the Cloud Data Loss Prevention API to scan the secrets, and store them in Cloud SQL.
  • D. Deploy the SCM to a Compute Engine VM with local SSDs, and enable preemptible VMs.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

Poprawna odpowiedź: B (Encrypt the secrets with a Customer-Managed Encryption Key (CMEK), and store them in Cloud Storage.)

Analiza poprawności:
W kontekście starszych pytań egzaminacyjnych, użycie Customer-Managed Encryption Key (CMEK) w połączeniu z Cloud Storage było uznawane za najlepszą dostępną praktykę do przechowywania sekretów poza kodem źródłowym. Szyfrowanie kluczem zarządzanym przez klienta zapewnia kontrolę nad dostępem i bezpieczeństwem danych, nawet jeśli dostęp do bucketa GCS zostanie uzyskany przez niepowołane osoby.

Dlaczego pozostałe są błędne:
A. Cloud Source Repositories + Cloud SQL: Przechowywanie haseł w bazie danych bez dodatkowych zabezpieczeń (jak aplikacyjne szyfrowanie) nie rozwiązuje problemu bezpieczeństwa – jedynie przenosi sekrety z systemu SCM do bazy danych.
C. Cloud Data Loss Prevention (DLP) API: To narzędzie służy do identyfikacji i maskowania wrażliwych danych w już istniejących zbiorach. Nie jest przeznaczone do zarządzania cyklem życia sekretów.
D. SCM na Compute Engine z lokalnym SSD: To podejście czysto infrastrukturalne, które w żaden sposób nie adresuje problemu bezpiecznego przechowywania sekretów (hasła nadal byłyby w plikach konfiguracyjnych wewnątrz SCM).

Wskazówki egzaminacyjne:
- "Secret Manager": Jeśli w pytaniu pojawia się nowsza usługa GCP (jak Secret Manager), zawsze wybieraj ją jako rozwiązanie dedykowane.
- "Best practice (historyczne)": Jeśli pytanie jest stare i nie ma opcji Secret Manager, szukaj wzorca: Szyfrowanie (CMEK/KMS) + Izolacja w bezpiecznym storage'u (Cloud Storage).
- Eliminacja: Odpowiedzi sugerujące bazy danych (Cloud SQL) bez wspomnienia o szyfrowaniu zazwyczaj są błędne.

Analiza i Wyjaśnienie

Sugerowana odpowiedź: B

Analiza spornych kwestii (AI): To pytanie jest klasycznym przykładem 'pytania z historią'. Eksperci na forach zauważają, że Secret Manager (który jest obecnie najlepszą odpowiedzią) nie istniał w momencie tworzenia tego pytania. Dlatego uczący się muszą rozpoznać, że CMEK + Cloud Storage to 'najlepsza z dostępnych' metod, realizująca wymóg ochrony kryptograficznej i odizolowania od kodu źródłowego.
