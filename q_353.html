Question 353 / 361

Your financial services company needs to process customer personally identifiable information (PII) for analytics while adhering to strict privacy regulations. You must transform this data to protect individual privacy to ensure that the data retains its original format and consistency for analytical integrity. Your solution must avoid full irreversible deletion. What should you do?

  • A. Use Cloud Key Management Service (Cloud KMS) to encrypt the entire dataset with a customer-managed encryption key (CMEK).
  • B. Set up VPC Service Controls around the BigQuery project. Implement row-level encryption.
  • C. Implement a custom BigQuery user-defined function (UDF) by using JavaScript to hash all sensitive fields before they are loaded into the analytical tables.
  • D. Configure Sensitive Data Protection (SDP) to de-identify PII using format-preserving encryption (FPE).
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

✅ PRAWIDŁOWA ODPOWIEDŹ: D

Prawidłowa odpowiedź: D – Configure Sensitive Data Protection (SDP) to de-identify PII using format-preserving encryption (FPE).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO D JEST PRAWIDŁOWE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Format-preserving encryption (FPE) przez Sensitive Data Protection (Cloud DLP):
- FPE zachowuje format danych (np. numer karty pozostaje 16-cyfrowy po transformacji).
- Dane są użyteczne analitycznie (format zachowany).
- Deterministyczne = ten sam input → ten sam output → możliwość join.
- Odwracalne (z kluczem) = re-identyfikacja gdy konieczna.
- Spełnia regulacje finansowe (GDPR, PCI-DSS dla PII).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO INNE OPCJE SĄ BŁĘDNE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. ❌ CMEK = szyfruje całe datasety, nie de-identyfikuje konkretnych PII fields. Dane są dostępne przez autoryzowanych użytkowników w plaintext.
B. ❌ VPC SC + row-level encryption = perymetr + szyfrowanie wierszy. Nie de-identyfikuje PII (dane nadal są widoczne dla autoryzowanych).
C. ❌ Custom UDF z hashem = nieodwracalne, brak standardu, wymaga utrzymania. FPE jest bezpieczniejsze i deterministyczne.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WSKAZÓWKI EGZAMINACYJNE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• PII analytics + format preserving = SDP/DLP z FPE (CryptoReplaceFfxFpe).
• FPE = dane wyglądają "normalnie" ale są anonimizowane.
• "Transform to protect privacy while maintaining analytical utility" = FPE.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
REGUŁY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• PII de-identification z użytecznością = Cloud DLP/SDP + FPE.
• CMEK ≠ de-identification (szyfrowanie ≠ anonimizacja).

Kluczowe zagadnienia

Sugerowana odpowiedź: D

Analiza strategiczna: Pytanie o techniki ochrony danych w analityce. Format-Preserving Encryption (FPE) pozwala na analitykę na danych (np. joinowanie tabel), zachowując format danych, przy jednoczesnej ochronie prywatności zgodnie z regulacjami.
