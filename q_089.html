Question 89 / 361

You are the security admin of your company. You have 3,000 objects in your Cloud Storage bucket. You do not want to manage access to each object individually.
You also do not want the uploader of an object to always have full control of the object. However, you want to use Cloud Audit Logs to manage access to your bucket.
What should you do?

  • A. Set up an ACL with OWNER permission to a scope of allUsers.
  • B. Set up an ACL with READER permission to a scope of allUsers.
  • C. Set up a default bucket ACL and manage access for users using IAM.
  • D. Set up Uniform bucket-level access on the Cloud Storage bucket and manage access for users using IAM.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wyjaśnienie

Potwierdzona odpowiedź: D (Uniform bucket-level access + IAM)

Wyjaśnienie: 
Przy dużej liczbie obiektów (3000+) zarządzanie dostępem za pomocą ACL (Access Control Lists) dla każdego pliku staje się niemożliwe. Uniform bucket-level access wyłącza ACL i wymusza używanie wyłącznie IAM na poziomie bucketu, co zapewnia spójność, łatwość audytu i centralne zarządzanie.

Dlaczego pozostałe są błędne:
A, B. Udzielanie uprawnień 'allUsers' (publicznych) jest skrajnie niebezpieczne.
C. Default bucket ACL to nadal mechanizm ACL, który nie jest zalecany dla nowoczesnych, dużych środowisk i nie oferuje takiej przejrzystości jak IAM.

Wskazówki egzaminacyjne (Tips & Tricks):
Skalowalne zarządzanie GCS = Uniform bucket-level access + IAM.
