Question 360 / 361

Your organization uses Google Workspace as the primary identity provider for Google Cloud. Users in your organization initially created their passwords. You need to improve password security due to a recent security event. What should you do?

  • A. Conduct a security awareness training session, and set the password expiration settings to require more frequent updates.
  • B. Check the Enforce strong password box, and check Enforce password policy at the next sign-in.
  • C. Check the Enforce strong password box, and set the password expiration to occur more frequently.
  • D. Audit user activity for suspicious logins by using the audit and investigation tool.
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

✅ PRAWIDŁOWA ODPOWIEDŹ: B

Prawidłowa odpowiedź: B – Check the Enforce strong password box, and check Enforce password policy at the next sign-in.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO B JEST PRAWIDŁOWE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Problem: istniejące hasła są słabe (users initially created them). Odpowiedź B:
- "Enforce strong password" = wymaga spełnienia polityki złożoności hasła.
- "Enforce at next sign-in" = użytkownicy muszą zmienić hasło przy następnym logowaniu.
Razem = natychmiastowe wzmocnienie bezpieczeństwa bez czekania na wygaśnięcie haseł.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DLACZEGO INNE OPCJE SĄ BŁĘDNE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A. ❌ "Security awareness training + frequent expiration" = miękkie podejście. Bez wymuszenia silnego hasła, użytkownicy mogą nadal tworzyć słabe.
C. ❌ "Enforce strong + frequent expiration" = częstsze wygaśnięcie bez "enforce at next sign-in" = istniejące słabe hasła są nadal aktywne do momentu wygaśnięcia.
D. ❌ "Audit suspicious logins" = reaktywne, nie zmienia istniejących słabych haseł.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WSKAZÓWKI EGZAMINACYJNE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• "Improve existing password security" = enforce strong + enforce at next sign-in.
• "Enforce at next sign-in" = natychmiastowy efekt bez czekania.
• Frequent expiration ≠ rozwiązanie dla istniejących słabych haseł.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
REGUŁY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Natychmiastowe wzmocnienie haseł = enforce strong + enforce at next sign-in.
• Expiration = pasywne (czeka na wygaśnięcie), nie natychmiastowe.
