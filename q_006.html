Question 6 / 361

A customer needs to launch a 3-tier internal web application on Google Cloud Platform (GCP). The customer's internal compliance requirements dictate that end-user access may only be allowed if the traffic seems to originate from a specific known good CIDR. The customer accepts the risk that their application will only have SYN flood DDoS protection. They want to use GCP's native SYN flood protection. Which product should be used to meet these requirements?

  • A. Cloud Armor
  • B. VPC Firewall Rules
  • C. Cloud Identity and Access Management
  • D. Cloud CDN
Show Suggested Answer Hide Answer
Suggested Answer: B

Wyjaśnienie

**Poprawna odpowiedź: B**

**1. Kompleksowe wyjaśnienie poprawnej odpowiedzi:**
Wymagania klienta to:
- Aplikacja jest **wewnętrzna** (internal).
- Dostęp może być dozwolony tylko ze znanych, bezpiecznych adresów IP (CIDR).
- Klient akceptuje ryzyko SYN flood i chce skorzystać z natywnej ochrony GCP.
Dla aplikacji wewnętrznej (czyli bez zewnętrznego Load Balancera) najlepszym i najbardziej bezpośrednim rozwiązaniem spełniającym te kryteria są **VPC Firewall Rules (B)**. Reguły zapory sieciowej VPC filtrują ruch na poziomie hypervisora (dla każdej instancji) i pozwalają na precyzyjne ograniczenie źródłowych adresów IP (Source CIDR). Dodatkowo, mechanizm śledzenia połączeń (connection tracking) w zapaporze sieciowej VPC zapewnia wbudowaną ochronę przed atakami TCP SYN flood poprzez odrzucanie nieprawidłowych pakietów.

**2. Wyjaśnienie niepoprawnych odpowiedzi:**
- **A. Cloud Armor:** Cloud Armor to usługa ochrony przed atakami DDoS i WAF, ale działa wyłącznie z zewnętrznymi load balancerami (External HTTP(S) Load Balancing). Nie może być stosowana do filtrowania ruchu wewnętrznego.
- **C. Cloud IAM:** Służy do autoryzacji użytkowników i kont usługowych (dostęp do API GCP), a no nie filtruje ruchu sieciowego na poziomie adresów IP.
- **D. Cloud CDN:** Służy do buforowania treści statycznych i optymalizacji wydajności dla użytkowników zewnętrznych, nie filtruje dostępu po IP i nie chroni sieci wewnętrznych.

**3. Wskazówki i pułapki egzaminacyjne (Tips & Tricks):**
- Słowo-klucz: **Internal** web application. Cloud Armor odpada, ponieważ chroni tylko zasoby wystawione na świat przez Zewnętrzny Load Balancer.
- Reguły firewall w GCP są stanowe (stateful) i są aplikowane bezpośrednio na interfejsach sieciowych maszyn wirtualnych.

**4. Reguły wyboru odpowiedzi:**
- Filtrowanie IP dla ruchu wewnętrznego -> VPC Firewall Rules.
- Filtrowanie IP/WAF dla ruchu zewnętrznego -> Cloud Armor.

**5. Dodatkowe źródła:**
