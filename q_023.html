Question 23 / 361

Leadership team is concerned that PII is being stored as part of the regular chat logs. You want to resolve this concern while still maintaining data utility. What should you do?

  • A. Use Cloud KMS to encrypt PII.
  • B. Use Object Lifecycle Management to discard chat records.
  • C. Use image inspection and redaction actions of the DLP API.
  • D. Use generalization and bucketing of the DLP API.
Show Suggested Answer Hide Answer
Suggested Answer: C

Wyjaśnienie

Poprawna odpowiedź: C (Use image inspection and redaction actions of the DLP API.)

Analiza poprawności:
DLP (Data Loss Prevention) API to zaawansowane narzędzie GCP do identyfikacji, monitorowania i ochrony danych wrażliwych. W przypadku logów tekstowych lub obrazów (np. zrzutów ekranu z czatów), DLP API oferuje potężne mechanizmy "inspection" (wykrywanie wzorców: numery kart, adresy email, imiona) oraz "redaction" (trwałe usunięcie lub zamaskowanie tych danych). Jest to jedyny sposób, aby oczyścić dane (usunięcie PII) przy jednoczesnym zachowaniu użyteczności reszty logów (Data Utility) dla celów analitycznych.

Dlaczego pozostałe są błędne:
A (Cloud KMS): KMS służy do szyfrowania danych (np. danych w spoczynku). Szyfrowanie nie usuwa danych z logów – sprawia tylko, że są one nieczytelne dla osób bez klucza, ale sama informacja (PII) nadal tam jest fizycznie obecna.
B (Object Lifecycle Management): Ta usługa automatyzuje usuwanie lub przenoszenie plików (np. "usuń logi starsze niż 30 dni"). Usunięcie całych plików/logów niszczy użyteczność danych, podczas gdy my chcemy logi zatrzymać, ale bez PII.
D (Generalization and bucketing): Techniki te służą do anonimizacji danych STRUKTURALNYCH (np. zamiana konkretnego wieku 28 na zakres "20-30"). Dla nieustrukturyzowanych logów tekstowych lub obrazów, "Redaction" (usunięcie/zamaskowanie) jest dużo bardziej efektywne i zgodne z praktyką czyszczenia logów.

Wskazówki egzaminacyjne:
- "Chat logs" / "Images" + "PII": Zawsze wybieraj DLP API.
- "Maintain data utility": To hasło sugeruje, że chcesz usunąć tylko wrażliwe elementy, zostawiając resztę logów. To definicja "Redaction".
- Eliminacja: Jeśli pytanie pyta o usuwanie PII z tekstów/obrazów, odrzuć KMS (szyfrowanie to nie usuwanie) i Lifecycle (usuwa wszystko).

Analiza i Wyjaśnienie

Sugerowana odpowiedź: C

Analiza spornych kwestii (AI): DLP API posiada ponad 150 wbudowanych detektorów (tzw. "infoTypes"), które automatycznie rozpoznają numery kart płatniczych, adresy, imiona czy daty urodzenia w strumieniach tekstowych. To sprawia, że proces redakcji jest niezwykle szybki i nie wymaga ręcznego pisania wyrażeń regularnych.
