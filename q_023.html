Question 23 / 361

When working with agents in the support center via online chat, your organization's customers often share pictures of their documents with personally identifiable information (PII). Your leadership team is concerned that this PII is being stored as part of the regular chat logs, which are reviewed by internal or external analysts for customer service trends.
You want to resolve this concern while still maintaining data utility. What should you do?

  • A. Use Cloud Key Management Service to encrypt PII shared by customers before storing it for analysis.
  • B. Use Object Lifecycle Management to make sure that all chat records containing PII are discarded and not saved for analysis.
  • C. Use the image inspection and redaction actions of the DLP API to redact PII from the images before storing them for analysis.
  • D. Use the generalization and bucketing actions of the DLP API solution to redact PII from the texts before storing them for analysis.
Show Suggested Answer Hide Answer
Suggested Answer: C

Wyjaśnienie

**Potwierdzona odpowiedź: C**

**Reguła Egzaminacyjna (Exam Rule):**
DLP API (Data Loss Prevention) umożliwia automatyczną identyfikację, inspekcję i redakcję (usuwanie/maskowanie) danych wrażliwych w obrazach i tekście.

**Haczyki egzaminacyjne (Exam Traps):**
- A: Szyfrowanie KMS nie usuwa PII, jedynie je ukrywa, co utrudnia analizę.
- B: Usunięcie danych (Discard) uniemożliwia analizę trendów.
- D: Generalizacja tekstu nie rozwiązuje problemu PII zawartego w obrazach (dokumentach).

**Głębokie wyjaśnienie techniczne:**
W modelu współdzielonej odpowiedzialności, klient odpowiada za poufność danych przetwarzanych przez jego aplikacje. Obrazy dokumentów zawierają nieustrukturyzowane dane PII. Funkcje DLP API do przetwarzania obrazów wykorzystują OCR i rozpoznawanie wzorców, aby wykryć i zamaskować (redact) PII przed zapisem w bazie logów. Pozwala to na zachowanie "utility" (użyteczności) danych do analizy trendów bez naruszania prywatności użytkowników.

Analiza i Podsumowanie Dyskusji (AI)

Analiza i Wyjaśnienie

Sugerowana odpowiedź: C

Analiza spornych kwestii (AI): DLP API posiada ponad 150 wbudowanych detektorów (tzw. "infoTypes"), które automatycznie rozpoznają numery kart płatniczych, adresy czy imiona. To sprawia, że proces redakcji jest niezwykle skuteczny i zgodny z regulacjami typu RODO/GDPR czy PCI DSS bez konieczności ręcznego definiowania skomplikowanych reguł.
