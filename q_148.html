Question 148 / 361

Which Google Cloud service should you use to enforce access control policies for applications and resources?

  • A. Identity-Aware Proxy
  • B. Cloud NAT
  • C. Google Cloud Armor
  • D. Shielded VMs
Show Suggested Answer Hide Answer
Suggested Answer: A

Wyjaśnienie

1. Prawidłowa odpowiedź lub odpowiedzi:
A. Identity-Aware Proxy

2. Kompleksowe wyjaśnienie dlaczego dana odpowiedź jest prawidłowa (Analiza):
Pytanie dotyczy wyboru usługi Google Cloud służącej do wdrażania i egzekwowania polityk kontroli dostępu do aplikacji i zasobów:
- Identity-Aware Proxy (IAP) to centralny punkt kontroli dostępu dla aplikacji i maszyn wirtualnych działających w Google Cloud. IAP weryfikuje tożsamość użytkownika (Identity) oraz kontekst jego żądania (Context-Aware Access, np. adres IP, stan bezpieczeństwa urządzenia) przed zezwoleniem na połączenie. Działa w modelu Zero Trust, co pozwala na rezygnację z tradycyjnych sieci VPN i ochronę aplikacji przed nieautoryzowanym dostępem na poziomie warstwy aplikacyjnej.

3. Wyjaśnienie z osobna każdej niepoprawnej odpowiedzi:
- B. Cloud NAT: Jest usługą sieciową realizującą translację adresów IP dla wychodzącego ruchu maszyn wirtualnych z sieci prywatnej do internetu. Nie kontroluje dostępu użytkowników do aplikacji ani nie analizuje tożsamości.
- C. Google Cloud Armor: Jest to zapora sieciowa typu WAF (Web Application Firewall) i ochrona przed atakami DDoS na poziomie warstwy 3/4 oraz warstwy 7. Służy do blokowania złośliwego ruchu (np. SQLi, XSS), ale nie zarządza uwierzytelnianiem i autoryzacją użytkowników IAM do aplikacji.
- D. Shielded VMs: Zapewniają ochronę na poziomie sprzętu/systemu operacyjnego maszyn wirtualnych (ochrona bootloadera, wykrywanie rootkitów). Nie zarządzają politykami dostępu użytkowników do zasobów aplikacyjnych.

4. Wskazówki, hinty, tips and tricks:
- IAP (Identity-Aware Proxy) to kluczowy element architektury bezpieczeństwa BeyondCorp (Zero Trust) w chmurze Google Cloud.
- Pozwala na precyzyjne sterowanie dostępem za pomocą ról IAM (np. IAP-secured Web App User).

5. Reguły wyboru odpowiedzi (Słowa kluczowe):
- Kontrola dostępu do aplikacji i maszyn na bazie tożsamości / Zero Trust -> Identity-Aware Proxy (IAP).

6. Dodatkowe źródła i dokumentacja:
- Identity-Aware Proxy overview: https://cloud.google.com/iap/docs/concepts-overview
