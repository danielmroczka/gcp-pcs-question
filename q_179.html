Question 179 / 361

You need to set up a Cloud Interconnect connection between your company's on-premises data center and VPC host network. You want to make sure that on-premises applications can only access Google APIs over the Cloud Interconnect and not through the public internet. You are required to only use APIs that are supported by VPC Service Controls to mitigate against exfiltration risk to non-supported APIs. How should you configure the network?

  • A. Enable Private Google Access on the regional subnets and global dynamic routing mode.
  • B. Create a CNAME to map *.googleapis.com to restricted.googleapis.com, and create A records for restricted.googleapis.com mapped to 199.36.153.8/30.
  • C. Use private.googleapis.com to access Google APIs using a set of IP addresses only routable from within Google Cloud, which are advertised as routes over the connection.
  • D. Use restricted googleapis.com to access Google APIs using a set of IP addresses only routable from within Google Cloud, which are advertised as routes over the Cloud Interconnect connection.
Show Suggested Answer Hide Answer
Suggested Answer: D

Wskazówki egzaminacyjne (Tips & Tricks)

Reguła Egzaminacyjna (Exam Rule): 
Jeśli scenariusz dotyczy zabezpieczania zasobów chmurowych (GCP), zawsze wybieraj rozwiązanie typu Managed (SCC, Secret Manager, Cloud KMS), a unikaj rozwiązań self-managed, chyba że pytanie wyraźnie wymaga dostosowania niskopoziomowego.

Haczyki egzaminacyjne (Exam Traps):
- Pułapka IAM: Pytania o uprawnienia często sugerują 'Project Owner' – zawsze szukaj 'Least Privilege' (np. 'Role: Secret Manager Secret Accessor').
- Pułapka Sieciowa: Często mylone są VPC Peering (wydajność) oraz VPN (szyfrowanie/on-premise).

Głębokie wyjaśnienie techniczne:
Rozwiązanie bazuje na GCP Shared Responsibility Model. Google zarządza bezpieczeństwem infrastruktury (Physical, Network, Host), podczas gdy administrator zarządza tożsamością (IAM), danymi (Encryption, Cloud KMS) i regułami dostępu (VPC Firewall).

Wyjaśnienie

Poprawna odpowiedź: D (Use restricted.googleapis.com to access Google APIs using a set of IP addresses only routable from within Google Cloud, which are advertised as routes over the Cloud Interconnect connection)

Dlaczego ta odpowiedź jest poprawna:
- restricted.googleapis.com: Jest to specjalna domena Google Cloud przeznaczona dla organizacji korzystających z VPC Service Controls (VPC SC). Kluczową cechą tej domeny jest to, że rozwiązuje się ona na zakres adresów IP (199.36.153.4/30), który obsługuje TYLKO te API Google, które są wspierane przez VPC SC.
- Zapobieganie eksfiltracji: Używając `restricted.googleapis.com`, masz pewność, że ruch z on-premises nie trafi do uslug, które nie są objęte perymetrem bezpieczeństwa (np. osobiste konta Gmail czy dyski GDrive), co spełnia wymóg "mitigate against exfiltration risk to non-supported APIs".
- Łączność hybrydowa: Rekordy A dla tej domeny muszą zostać rozpropagowane przez BGP (Cloud Router) do Twojej sieci on-premises, aby ruch mógł płynąć przez Cloud Interconnect bez wychodzenia do publicznego internetu.

Analiza niepoprawnych odpowiedzi:
- A. Private Google Access on regional subnets: Private Google Access (PGA) pozwala VM-om wewnątrz Google Cloud (które nie mają publicznych IP) na łączenie się z API. Nie rozwiązuje to problemu dostępu z sieci on-premises (do tego służy PGA for On-Premises, ale wymaga odpowiedniej domeny DNS).
- B. CNAME and A records: Choć opisuje mechanizm techniczny DNS, opcja D jest bardziej kompletna, ponieważ wspomina o rozgłaszaniu tras (advertised as routes), co jest niezbędne, aby adresy IP 199.36.153.8/30 były osiągalne z on-premises. Ponadto IP 199.36.153.8/30 to zakres dla `private.googleapis.com`, a nie `restricted`.
- C. private.googleapis.com: Ta domena obsługuje większość usług Google, w tym te, które NIE są wspierane przez VPC Service Controls. Użycie jej nie spełnia więc wymogu ograniczenia dostępu tylko do usług wspieranych przez VPC SC w celu ochrony przed eksfiltracją.

Wskazówki i triki (Tips & Tricks):
- "VPC Service Controls" + "On-premises" = `restricted.googleapis.com`.
- "Most Google APIs" + "On-premises" = `private.googleapis.com`.
- Zakres `restricted`: 199.36.153.4/30.
- Zakres `private`: 199.36.153.8/30.

Praktyczne informacje na egzamin:
- Zapamiętaj: `restricted` jest bardziej bezpieczne (węższy zakres usług), `private` jest bardziej elastyczne (szerszy zakres usług).
- Konfiguracja wymaga trzech kroków: (1) Konfiguracja DNS on-prem, (2) Konfiguracja Cloud Routera do rozgłaszania tras, (3) Konfiguracja Firewalli.

Analiza i Podsumowanie (AI)

Kluczowe zagadnienia

Sugerowana odpowiedź: D

Analiza strategiczna: To pytanie testuje Twoją znajomość architektury "Secure Hybrid Connectivity". W świecie przedsiębiorstw nie wystarczy połączyć biura z chmurą. Musisz kontrolować, do których konkretnie usług Google pracownicy mogą wysyłać dane. `restricted.googleapis.com` jest "bezpiecznym tunelem" dla API, który w połączeniu z perymetrem VPC SC tworzy kompletną barierę przed wyciekiem danych.

Dodatkowe wskazówki

  • Ruch do `restricted.googleapis.com` nie wymaga od użytkowników posiadania publicznych adresów IP ani korzystania z NAT-a.
  • Pamiętaj, że jeśli usługa nie jest wspierana przez VPC SC, próba połączenia się z nią przez domenę `restricted` zakończy się błędem DNS lub brakiem odpowiedzi.
